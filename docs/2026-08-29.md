## 변경 사항

### 1. 추론 지연 링 버퍼 + p50/p95/max 통계

**파일:** `src/detector_ort.c`, `include/yolo11.h`

`struct Detector`에 최근 256회 추론 시간을 저장하는 고정 크기 링 버퍼를 추가했다. 매 `detector_run()` 호출 후 추론 ms를 링 버퍼에 기록하고, insertion sort(n≤256)로 p50/p95/max를 계산해 `DetectorRunStats`에 저장한다.

```c
/* DetectorRunStats 신규 필드 */
double inference_p50_ms;
double inference_p95_ms;
double inference_max_ms;
```

**버퍼 정책:** `LATENCY_BUF_SIZE = 256`. 시작 시 1회 `calloc`, `detector_destroy()`에서 `free`. 프레임 수에 무관한 고정 크기라 기존 설계 원칙("모든 버퍼는 시작 시 한 번만 할당")을 유지한다.

p95가 p50의 2배를 넘으면 서멀 스로틀링이 의심되므로 `--metrics` JSON으로 확인한다.

### 2. ORT 세션 최적화

**파일:** `src/detector_ort.c`

`session_options` 설정 블록에 두 가지 최적화를 추가했다.

**Denormals-as-zero:**
```c
AddSessionConfigEntry("session.set_denormals_as_zero", "1")
```
Haswell(i5-4200U)에서 FP32 denormal 수는 수백 사이클 페널티가 있다. DAZ/FTZ 모드를 켜면 0으로 처리해 실질적인 속도 이득을 얻는다.

**웜업(`--warmup N`):**
```c
DetectorOptions.warmup_runs  /* 기본 0 */
```
시작 시 회색(114/255) 더미 프레임으로 N회 추론을 실행해 JIT 컴파일·메모리 매핑 초기화를 서비스 전에 소진한다. 첫 실제 프레임의 지연 스파이크가 사라진다.

**DirectML + INT8 경고:**
INT8 모델 파일명(`int8`)과 DirectML provider를 함께 쓰면 Intel HD 4400에서 오히려 느려질 수 있어 자동으로 경고를 출력한다.

### 5. `scripts/quantize.py` — static INT8 양자화

**파일:** `scripts/quantize.py` (신규)

YOLO ONNX 모델을 INT8으로 양자화하는 스크립트다.

**기본 모드: static (권장)**
```sh
python scripts/quantize.py --model yolo11n-pose-416.onnx --calib-dir samples/
```
- `quant_pre_process()` → shape inference + 그래프 최적화 선행 적용
- `YoloCalibReader`: C 코드의 `letterbox_to_nchw()`와 동일한 전처리 (114 패딩, 중앙 정렬, /255.0, NCHW)로 캘리브레이션 데이터 공급. 전처리가 어긋나면 캘리브레이션 통계가 틀려 정확도가 크게 떨어진다.
- `quantize_static()` — QDQ 노드 삽입, QInt8 가중치 변환

**dynamic 모드** (`--mode dynamic`)도 지원하지만 CNN에는 거의 효과가 없어 권장하지 않는다.

**i5-4200U 기대치:** Haswell은 VNNI가 없어 AVX2 `u8s8s32` 경로를 탄다. 기대 속도 향상은 **1.5~2.5×** 수준이다. 일부 문서의 "2~4×"는 Cascade Lake+(VNNI 있음) 기준이다.

### 6. `scripts/bench.ps1` + `scripts/bench.sh` — 성능 비교

**파일:** `scripts/bench.ps1`, `scripts/bench.sh` (신규)

같은 입력 영상으로 FP32/INT8 모델을 각각 돌려 추론 시간·p95·CPU ms/frame을 표로 비교 출력한다.

```
======================================================================
모델     추론횟수    총추론(s)  p50(ms)  p95(ms)  max(ms)  CPU ms/frame
----------------------------------------------------------------------
FP32          300        12.6     41.2     59.8     82.1         38.4
INT8          300         7.1     27.8     39.5     51.0         25.7
======================================================================
INT8 속도 향상 (총 추론 시간): 1.77x
```
