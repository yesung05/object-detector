## A-1 포즈 진단
[상세](pose-aihub-gt-diagnosis-2026-11-07.md). 쓰러짐 병목(저신뢰 20%·몸통 판정 불가 15%)이 포즈 모델에서 온다는 것을 정답 관절로 직접 확인했다. 관절 점수가 틀려도 0.4 이상이 99% 라 룰의 "보이는 관절" 조건은 쓰러진 사람에서 걸러 내지 못한다.

## A-2 포즈 파인튜닝 ([사전등록](prereg_pose_aihub.md))
pool 장면 프레임(전도 6.5천·폭행/파손 각 3.3천) + COCO 1.2만, 하이퍼파라미터 고정(`finetune_pose_original.py` 와 동일).

| 실험 | 라벨 | COCO 포즈 mAP50 (원본 0.739) | dev 누운 사람 PCK (원본 0.459) | dev 서 있는 사람 PCK (원본 0.887/0.904) |
|---|---|---|---|---|
| 1차 | 관절 외곽+15%, 머리 빠짐(버그) | 0.553 | (미측정) | — |
| 2차 | 머리 포함 | 0.543 | **0.815** | 0.921 / 0.931 |
| 3차 | 무라벨 사람 의사 라벨 + COCO식 박스 + 얼굴 관절은 원본 모델 값 | **0.641** | 0.787 | 0.917 / 0.928 |

- 참고: COCO 단독으로 같은 레시피를 파인튜닝하면 −2.7pt(`runs/pose/pose-original-finetune`). 하락의 대부분은 AI-Hub 데이터에서 온다.
- 3차에서 무라벨 사람(1,797명 추가, 애매한 프레임 969장 제외)과 박스 모양을 고치자 하락이 절반으로 줄었다(−19.6 → −9.8pt). 남은 원인 후보: 얼굴 5점 정답이 없는 사람이 많음, 손/발 ↔ 손목/발목 근사, 연출 매장 7곳의 장면 편중.
- 사전 규칙대로 3차 No-Go 로 **포즈 파인튜닝은 중단**한다. 다시 한다면: AI-Hub 비율을 낮추고(예: 1:3), 손목·발목은 원본 모델 값으로 두고 몸통·무릎만 정답을 쓰는 방식으로 새 사전등록부터.

## B 쓰레기 투기 — 학습 기준 + 주인 추정
빈 매장 사진 없이 사람이 없는 블록에서 배경을 배우고(`residue_learn_background`), 물건이 생길 때 곁에 있던 트랙이 떠난 뒤 확정되면 `item_left`.
유기(11) dev 147클립, 음성 210클립(3.5시간), 정답 구간 뒤 10초까지 인정.

| 설정(확정 5초) | 재현율 | 오탐/시간 |
|---|---|---|
| 기본(사람 여백 1블록, 최소 3블록) | 2.7% (4/147) | 7.7 |
| 여백 3·최소 6 | 1.4% | 4.6 |
| 여백 4·최소 10 | 1.4% | 3.1 |

- 잔류 후보 대부분이 사람 주변의 움직임·그림자 흔적이었다(클립당 `residue_unknown` 약 27건). 연출 클립은 물건을 두고도 사람이 화면에 남아 "주인이 떠남" 조건이 드물게 성립한다.
- **No-Go**. 코드는 재현용 커밋(`385164e`)으로 남기고 바로 되돌렸다. 잔류물 이벤트가 다시보기에 안 남던 버그 수정만 유지(`f2129ad`).
