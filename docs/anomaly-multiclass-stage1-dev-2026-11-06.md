# 이상행동 확장 탐지 — 1단계(1차 필터 분리도) dev 측정 결과 (2026-11-06)

사전 등록: `docs/prereg_anomaly_multiclass.md`(결과 전 커밋). 도구: `scripts/measure_pair_features.py`(사람 쌍·손-입 특징), `scripts/measure_anomaly_filter_auc.py`(화소·손목 속도), 실행: `scripts/run_stage1_dev_measure.sh`. 모델 `yolo11n-pose-416x224` FP32, 기존 추론 캐시 재생, **dev만**(test 미사용), 장면당 1클립, 양성 32~42클립 / 음성 140클립(7개 클래스 × 20). 3fps 연출 영상이라 절대 수치는 현장 값이 아니다.

판정 규칙(사전 고정): Go = 같은 특징이 정상 95% 스킵에서 클립 TPR ≥ 0.90(엄격: 전체 정상 임계값과 클립 내부 정상 임계값 둘 다). dev에서 어떤 특징의 `auc_vs_all_normal` 도 0.75 미만이면 조기 중단(no-go).

## 해석

- **폭행만 신호가 있다.** `fight_score`는 두 사람이 가깝고 팔다리가 빠르게 움직일 때 커진다. 전체 정상 대비 AUC 0.96으로 높지만, 이 중 상당 부분은 "폭행 클립은 거의 항상 2인 이상"이라는 사람 수 효과다. 같은 클립의 이벤트 밖 프레임과 비교한 AUC는 0.835, 엄격 TPR 0.844로 Go 기준 0.90에 못 미친다. 즉 **1차 룰만으로 확정하기엔 부족하고, 의심 구간을 좁히는 1차 필터로는 쓸 수 있다**(2차 AI 후보).
- **흡연은 주의가 필요한 결과다.** `hand_mouth_sust`의 클립 TPR은 0.879로 Go 기준에 가깝지만 프레임 단위 AUC는 0.60이다. 클립 TPR은 "이벤트 구간(수십 프레임) 안에 연속 2프레임만 넘으면 성공"이라 관대하고, 정상 쪽은 프레임 5%가 임계값을 넘는다. 이 임계값을 정상 클립에 적용하면 클립당 평균 수 프레임이 넘는다(정상 클립 트리거율은 이번에 측정하지 않았다). 사전 규칙(AUC < 0.75)에 따라 no-go로 기록하되, **손-입 근접만으로는 하품·통화·턱 괴기와 구분이 안 된다**는 점이 원인으로 보인다(확인하지 않음). 크롭 분류기는 계획서상 후순위이며 이번 범위에서는 하지 않는다.
- 절도·유기·방화·파손은 어떤 특징도 AUC 0.70을 넘지 못했다. 키포인트·화소 차분 수준의 신호로는 분리되지 않는다. 유기는 기준 이미지 문제(`anomaly-dataset-improvements-2026-11-05.md` 7절)로 잔류물 룰도 평가할 수 없다.

## 한계

- dev 측정이며 pool 확정·test 1회는 하지 않았다. 폭행 `fight_score`의 임계값·특징은 dev에서만 골랐다.
- 음성에 "같은 클래스의 정상 구간"은 양성 클립 이벤트 밖 프레임만 있다. 일반 손님의 평상시 행동(대화·악수·포옹·아이 놀이 등) 음성은 이 데이터에 거의 없어 **폭행 오탐률은 측정하지 못했다**.
- 사람 수 효과를 완전히 분리하지 못했다(클립내 AUC 0.835는 같은 클립 안에서 이벤트 전후 비교).
- 3fps, 배우 1~2명, 매장 7곳. i5-4200U 비용 미측정(1차 특징은 박스·관절 연산뿐이라 영상 디코딩 불필요).
- 클립 TPR은 정상 클립의 트리거율을 반영하지 않는다.

## 다음 단계 제안

1. **폭행만 2단계로 진행**: 의심 구간(`fight_score` > 임계값)에서 두 사람 키포인트 궤적을 입력으로 하는 소형 분류기를 학습하고, 학습 전에 목표(재현율·FA/h)를 prereg 문서에 추가 커밋한다. 평가는 pool, 매장 단위 hold-out 검증 포함.
2. 흡연·절도·유기·방화·파손은 이번 범위에서 종료(no-go 기록). 흡연은 크롭 기반 2차 분류기를 별도 과제로 남긴다.
3. 새 룰·2차 모델은 AI-Hub 약관 확인 전까지 배포하지 않는다.
