# 학술대회 발표 논문 주제 후보 — 무인 매장 환경 관리 (CV 응용)

> 작성일: 2026-09-09
> 대상: `object-detector` (컴퓨터비전 기반 무인 카페 환경 관리 소프트웨어)
> **범위 제한**: 성능 최적화·경량화(추론 게이팅, 양자화, letterbox 패딩, CPU 벤치마크)는
> **다른 연구자가 담당하므로 본 문서의 주제에서 제외**한다. 4장에 중복 회피 기준을 별도 정리했다.

---

## 1. 이 프로젝트가 "환경 관리" 관점에서 가진 자산

최적화를 뺀 나머지, 즉 **"무엇을 어떻게 판단하는가"** 에 해당하는 것만 추린다.

| 자산 | 위치 | 도메인적 가치 |
|---|---|---|
| **익명 그룹 단위 주문 검증 설계** | `docs/order-group-verification-design.md`, `docs/시나리오.md` | 개인 식별 없이 주문 상태를 판정하는 3단계 신뢰도 모델 |
| **3-state 판정** (`CONFIRMED`/`LIKELY`/`UNVERIFIED`) | 위 문서 | 이진 판정을 거부하고 "확정 못 하면 미확정"을 1급 상태로 승격 |
| **사람 트랙 + 물체 + 픽셀 신호의 증거 융합** | `src/rules.c: rules_evaluate/_objects` | 세 종류 관측을 결합해 이상 상황을 판정 |
| **가용 관측에 적응하는 쓰러짐 판정** | `src/rules.c: is_horizontal_pose` | keypoint 유무·엉덩이 관절 유효성에 따라 임계값을 전환 |
| **이중 기준 프레임 문 개폐 판정** | `src/door.c`, `include/door.h` | 조명 변화에 강인. "열림 기준"도 함께 두어 거리 비교로 전환 |
| **HSV 히스토그램 + limbo 기반 단기 Re-ID** | `src/tracks.c`, `include/tracks.h` | 얼굴 없이 사각지대 재진입을 복원. 개인 식별은 명시적 비목표 |
| **latch / 히스테리시스 / 유예 시간 이벤트 확정** | `rules.c`, `door.c`, `camera_health.c` | 알람 폭주 억제 — 무인 운영에서 실사용성을 좌우 |
| **카메라 자체의 장애 감지** | `src/camera_health.c` | 백화·암전·정지. 감시 시스템의 자기 진단 |
| **매장 설치 유형 분류 (A/B/C)** | `docs/시나리오.md` | 단일 광각 / 다중 카메라 사각지대 / 복층 매장 |
| **매장별 설정 외부 주입** | `src/config.c`, `config/store.example.ini`, 대시보드 | 매장 규모·점주 정책별 임계값 분리 |
| **온디바이스 처리 (영상 외부 전송 금지)** | 설계 원칙 | 프라이버시 논점 확보 |

**환경 관리 관점의 핵심 무기**
> 대부분의 무인 매장 CV 연구가 "행동을 정확히 분류하는 모델"을 만드는 데 집중하는 반면,
> 이 프로젝트는 **"모델이 틀릴 것을 전제하고, 부족한 증거를 어떻게 다룰지"** 를 설계 문제로 다룬다.
> 사각지대·가림·조명 변화·개인 ID 단절을 **결함이 아니라 입력 조건으로 받아들이는 판정 체계** — 이것이 차별점이다.

## 2. 주제 후보

### 후보 ① — 익명 그룹 단위 주문·체류 검증 (⭐ 1순위 추천)

> 가제: *"개인 식별 없이 그룹 단위 증거 융합으로 주문 상태를 판정하는 무인 매장 관리 기법"*

**한 문장 주장**
> 무인 매장에서 "이 손님이 주문했는가"를 개인 단위로 확정하려면 개인 식별이 필요하고 이는 프라이버시와 충돌한다. 판정 단위를 개인이 아닌 **익명 그룹**으로 옮기고, 결제 수량을 확정 사실이 아닌 **커버 가능 인원 가설**로 다루면, 개인 식별 없이도 운영에 쓸 수 있는 수준의 판정이 가능하다.

**기여점**
1. **판정 단위의 전환** — `track_id`(개인) → `group_id`(테이블/근접 익명 집합)
   개인 ID가 사각지대에서 끊기는 것을 전제로 삼는다는 점이 기존 접근과 다르다
2. **증거의 유형 구분** — 결제 수량(order credit)은 *가설*, 주문 후 새로 등장한 컵·트레이(product evidence)는 *보강 증거*
3. **3-state 판정 모델** — `CONFIRMED_ORDERED` / `LIKELY_ORDERED` / `UNVERIFIED`
   이진 판정을 거부하고 "증거 부족"을 독립 상태로 승격. `UNVERIFIED`는 미주문 확정이 아니라 점검 후보
4. **키오스크 SW 비침습 연동** — 기존 POS를 수정하지 않고 DB/로그/영수증 읽기 전용 어댑터로 결제 이벤트 취득

**실험 설계**

| 항목 | 내용 |
|---|---|
| 베이스라인 | (a) 개인 `track_id` 단위 주문 배정 (b) 컵 개수 대비 인원 수 단순 비교 |
| 제안 기법 | 그룹 단위 배정 + 상품 증거 결합 + 3-state |
| 지표 | 상태별 정확도, **오탐률(정상 손님을 UNVERIFIED로 판정)**, 미탐률, ID 단절 발생 시 판정 유지율 |
| 시나리오 | 1인 1메뉴 / 4인 1결제 / 테이크아웃 / 사각지대 경유 후 재착석 / 외부 컵 반입 |
| 강조 | ID가 끊긴 상황에서 베이스라인은 무너지지만 제안 기법은 그룹 상태를 유지함을 보이는 것이 핵심 |

**난이도** 중상 — 설계 문서는 완성도가 높으나 **구현이 아직 코드에 없다**(현재는 키오스크 ROI 프록시 수준)
**신규성** 높음. "개인 식별 회피"와 "판정 성능"을 동시에 다루는 프레이밍이 강함
**주의** 결제 데이터 연동이 실제로 불가능하면 ROI 프록시로 대체하고 그 한계를 논문에 명시해야 함

### 후보 ② — 무인 매장 이상 상황 분류체계와 다중 증거 융합 판정

> 가제: *"무인 매장 이상 상황의 관측 근거 기반 분류와 계층적 증거 융합 판정 프레임워크"*

**한 문장 주장**
> 무인 매장의 이상 상황 10여 종은 각각 요구하는 관측 근거가 다르다. 이를 **픽셀 신호 / 사람 궤적 / 물체 관계** 세 계층으로 분류하면, 상황별로 최소한의 근거만 결합해 판정하는 통합 룰 체계를 만들 수 있다.

**기여점**

1. **이상 상황 taxonomy** — 요구 근거에 따른 분류

   | 근거 계층 | 이상 상황 | 판정 방식 |
   |---|---|---|
   | 픽셀 신호 | 출입문 개방, 카메라 백화·암전·정지 | 기준 프레임 차분 (AI 불필요) |
   | 사람 궤적 | 초과 장기 체류, 미주문 착석, 출입 제한 대상 진입 | 트랙 ID + 체류 시간 + ROI |
   | 사람 자세 | 실신·쓰러짐 | keypoint 기하 |
   | 물체 관계 | 반려동물 의자 착석, 외부 음식 반입, 쓰레기 투기 | 물체 bbox 간 IoU + 사람 부재 |

2. **증거 융합 규칙** — 단일 관측으로 판정하지 않는 사례 제시
   (예: `animal_on_furniture` = 동물 bbox ∩ 의자/테이블 bbox IoU ≥ 0.15 —
   IoU 임계를 낮게 잡는 이유는 동물이 의자 위에 있을 때 bbox 하단부만 겹치기 때문)
3. **AI 불필요 판정의 분리** — 문 개폐·카메라 장애처럼 딥러닝 없이 해결 가능한 항목을 명시적으로 분리
4. 상황별 latch/유예 시간 상태 머신으로 중복 알람을 억제하는 이벤트 확정 로직

**실험 설계**
- 시나리오별 연출 영상 기준 **상황별 검출률 / 오탐률 / 평균 검출 지연**
- 근거 계층별 기여 분석: 물체 증거를 뺐을 때 어떤 상황의 오탐이 늘어나는지
- 비교군: 모든 상황을 단일 모델 출력으로만 판정하는 구성

**난이도** 중 — `src/rules.c`에 상당 부분 구현됨. 시나리오 영상과 정답 라벨 확보가 관건
**신규성** 중. taxonomy 자체는 정리 성격이라, **증거 융합 규칙과 오탐 억제 결과**를 앞세워야 함

### 후보 ③ — 관측 가용성에 적응하는 저오탐 이상 감지 (⭐ 2순위 추천)

> 가제: *"관측 가용성에 적응하는 판정 임계 전환을 통한 무인 매장 이상 감지의 오탐 저감"*

**한 문장 주장**
> 실제 매장에서 CV 감지의 실패는 "못 잡는 것"보다 **"잘못 잡는 것"** 이 운영을 망가뜨린다. 관측 품질(keypoint 가용성, 조명 변화, 검출 신뢰도)에 따라 판정 임계를 전환하고 시간축 지속성 조건을 결합하면, 검출률을 크게 잃지 않고 오탐을 줄일 수 있다.

**기여점** — 이 프로젝트에서 **실제로 발생한 오탐과 그 해결책**이 근거다 (커밋 이력에 남아 있음)

1. **keypoint 가용성 적응형 쓰러짐 판정** (`is_horizontal_pose`)
   - keypoint 유효 시: bbox 종횡비 1.8배 + 머리·어깨·엉덩이 y좌표 표준편차 ≤ bbox 높이의 20%
   - keypoint 부족 시: 종횡비 2.2배로 **더 엄격하게** 전환
   - 핵심 관찰: **엉덩이(11·12) keypoint 없이 코+어깨만으로 y-std를 계산하면 해부학적으로 항상 작은 값이 나와 조건을 거의 항상 통과한다** → 관측이 부족할수록 기준을 강화해야 한다는 일반 원리
2. **이중 기준 프레임 문 개폐 판정** (`door.c`)
   - 단일 기준(닫힘)만 쓰면 "닫힘과의 차이 > 임계값 → 열림"이라 조명 변화에 오탐
   - 닫힘·열림 두 기준을 모두 두고 **어느 쪽에 더 가까운지 거리 비교**로 전환 → 조명 강인성 확보
3. **시간축 지속성 조건** — 순간 조건 충족을 이벤트로 보지 않음
   (쓰러짐 5초 지속, 문 개방 30초 지속, 카메라 이상 5프레임 연속 → 정상 입퇴장·일시적 자세를 걸러냄)
4. **latch 기반 중복 알람 억제** — 트랙당 1회 발화, 조건 해소 시 해제

**실험 설계**

| 항목 | 내용 |
|---|---|
| 베이스라인 | 고정 임계값(종횡비 1.2 단일 기준), 단일 기준 프레임 문 판정, 지속성 조건 없음 |
| 제안 기법 | 적응형 임계 전환 + 이중 기준 + 지속성 조건 |
| 지표 | **오탐률(FP/시간)**, 검출률, 검출 지연, ROC 유사 곡선 |
| 시나리오 | 앉아서 상체 숙임 / 팔 벌림 / 바닥의 물건 줍기 (쓰러짐 오탐 유발), 조명 점등·소등 (문 오탐 유발) |
| 강조 | **오탐이 몇 배 줄었는데 검출률은 유지됐다**는 대조가 그림 하나로 나오면 강력함 |

**난이도** 중하 — 구현이 이미 되어 있고, 개선 전/후 코드가 커밋 이력에 남아 있어 **베이스라인 재현이 쉽다**
**신규성** 중상. "적응형 임계 전환"이라는 일반 원리로 추상화하면 개별 트릭 나열을 넘어설 수 있음
**장점** 실험 부담이 후보들 중 가장 낮으면서 정량 결과는 잘 나오는 구조

### 후보 ④ — 설치 환경 이질성에 대응하는 구성 가능한 감지 프레임워크

> 가제: *"매장 구조 이질성을 고려한 무인 매장 영상 감지 시스템의 구성 가능 설계"*

**한 문장 주장**
> 무인 매장은 평수·카메라 화각·좌석 배치·복층 여부가 제각각이라 단일 임계값 세트가 성립하지 않는다. 설치 유형을 분류하고, 유형별로 **판정 가능한 범위 자체를 다르게 선언하는** 구조가 필요하다.

**기여점**
1. **설치 유형 분류** — A: 키오스크·좌석 단일 광각 / B: 다중 카메라 + 사각지대 / C: 복층(1층 키오스크 + 2층 좌석)
2. **유형별 판정 가능 범위 선언** — 유형 C에서 2층 카메라가 없으면 2층 인원의 주문 상태를 추정하지 않는다.
   "설치 범위 밖은 추정하지 않는다"를 설계 원칙으로 명문화
3. **매장별 설정 외부 주입 구조** — 체류 한도, 유예 시간, ROI, 활성화 기능을 코드 수정 없이 조정
4. 점주 정책(1인 1메뉴 적용 여부 등)을 켜고 끌 수 있는 정책 계층 분리

**난이도** 중 — 설계 논문 성격이라 정량 실험이 약해질 위험
**신규성** 중. 단독으로는 "구현 사례 보고"로 보일 수 있어, **동일 시스템을 서로 다른 유형의 매장에 설치한 비교 결과**가 있어야 논문이 된다
**추천** 단독보다는 후보 ①·②의 한 절로 흡수하거나, 실제 다중 매장 설치가 가능해질 때 선택

---

### 후보 ⑤ — 온디바이스 프라이버시 보존 무인 매장 관리

> 가제: *"영상 외부 반출 없는 온디바이스 무인 매장 관리 시스템의 프라이버시 설계"*

**한 문장 주장**
> 무인 매장 CCTV의 프라이버시 위험은 영상이 기기 밖으로 나가는 순간과 개인을 영구 식별하는 순간에 발생한다. 두 지점을 설계 수준에서 차단하면서도 운영에 필요한 판정은 유지할 수 있다.

**기여점**
1. **비목표의 명시** — 얼굴 인식·실명 식별·개인정보 수집을 하지 않는다는 것을 설계 제약으로 선언
2. **제한적 Re-ID** — 상체 HSV 히스토그램 기반 매칭을 **동일 카메라의 단기 가림 복원에만** 한정하고, limbo 시간 경과 후 폐기. 개인 식별 수단으로 쓰지 않음
3. **영상 유출 경로 차단** — FFmpeg가 `rtmp://`·`rtsp://`·`http://` URL을 투명하게 처리하는 위험과 경로 검증 대책
4. **최소 정보 이벤트 로깅** — 외부에 남기는 것은 이벤트 메타데이터뿐

**난이도** 중 — 정책·설계 논문 성격
**적합 세션** 정보보호·프라이버시 트랙. CV 트랙에서는 기술 신규성이 약하게 보일 수 있음
**추천** 단독보다 후보 ①의 보강 논거(개인 식별을 피해야 하는 *이유*)로 배치

---

## 3. 추천

### 1순위: **후보 ①** (익명 그룹 주문 검증) + **⑤를 동기(motivation)로 배치**

이유:
- **신규성이 가장 높다.** "개인 식별 없이 주문을 판정한다"는 프레이밍은 프라이버시와 성능을 동시에 다루는 구조라 심사에서 이야기가 된다
- 3-state 판정과 "증거 부족을 독립 상태로 승격"은 이진 분류 중심 연구와 명확히 구분된다
- 최적화 담당자의 주제와 **겹칠 여지가 사실상 없다** (판정 로직 vs 실행 효율)
- 다만 **구현이 아직 없다** — 남은 기간이 짧으면 위험

### 2순위: **후보 ③** (관측 적응형 저오탐)

이유:
- **구현이 이미 되어 있고 베이스라인이 커밋 이력에 남아 있어 실험 비용이 가장 낮다**
- 오탐 저감은 정량 결과가 깔끔하게 나오는 주제다
- 발표까지 기간이 촉박하다면 ③이 현실적인 선택

### 조합 제안

| 구성 | 주제 배치 |
|---|---|
| **안전한 단일 논문** | ③(본론) + ②의 taxonomy(배경) + ⑤(프라이버시 언급) |
| **도전적 단일 논문** | ①(본론) + ⑤(동기) + ④(적용 범위 한계) |
| **논문 2편** | 1편 = ① + ⑤ (설계·판정), 2편 = ② + ③ (룰 체계·오탐 저감) |

## 4. 최적화 담당자와의 중복 회피 기준

같은 프로젝트를 소재로 하므로 "같은 시스템 논문 아니냐"는 지적이 나올 수 있다.
아래 경계를 **서로 합의하고 논문에 명시**하는 것이 안전하다.

| 항목 | 최적화 담당 (상대) | 환경 관리 (본인) |
|---|---|---|
| 연구 질문 | 얼마나 **적은 비용**으로 돌릴 수 있는가 | 무엇을 **어떻게 판단**할 것인가 |
| 다루는 대상 | 추론 게이팅, 양자화, letterbox, CPU 벤치마크 | 판정 규칙, 증거 융합, 상태 모델, 오탐 저감 |
| 핵심 지표 | CPU 점유율, FPS, 추론 지연 | 검출률, **오탐률**, 검출 지연, 상태 판정 정확도 |
| 시스템 설명 | 게이트 구조를 상세히 | **1개 문단으로 축약하고 인용 처리** |
| 하드웨어 | i5-4200U 제약이 주제 | 배경 제약으로만 1~2문장 언급 |

**본인 논문에서 지켜야 할 선**
- CPU 점유율·FPS·추론 지연 수치를 **주 결과로 제시하지 않는다** (필요하면 "실시간 동작 가능함" 정도로 각주 처리)
- 게이팅·양자화는 "선행 구현되어 있음"으로 한 문장 처리하고 기여로 주장하지 않는다
- 반대로 상대 논문이 검출률·오탐률을 기여로 주장하지 않도록 협의

## 5. 논문 작성 전 확보해야 할 것

### 5.1 평가용 영상 데이터 (최우선)
- [ ] **이상 상황별 연출 영상 + 이벤트 발생 시각 정답 라벨** — 검출 지연·오탐률 산출에 필수
- [ ] **오탐 유발 시나리오 영상** — 후보 ③의 핵심. 앉아서 숙임 / 팔 벌림 / 물건 줍기, 조명 점등·소등
- [ ] 후보 ① 선택 시: 1인 1메뉴 / 다인 1결제 / 테이크아웃 / 사각지대 경유 재착석 시나리오
- [ ] 개인정보 처리 — 촬영 동의, 논문 게재 시 얼굴 마스킹 여부 확인

### 5.2 구현 보완
- [ ] **후보 ① 선택 시**: `group_id` 형성 로직, order credit 배정, 3-state 상태 머신이 **미구현**. 구현 기간 확보 필요
- [ ] 결제 이벤트 어댑터 — 실제 POS 연동이 불가하면 ROI 프록시 + 수동 주입으로 대체하고 한계 명시
- [ ] **정확도 측정 파이프라인** — 현재는 성능 지표만 있고 검출률·오탐률 산출 도구가 없다
- [ ] 베이스라인 재현용 플래그 (개선 전 임계값으로 되돌려 실행할 수 있어야 ablation이 가능)

### 5.3 선행연구 조사
- [ ] 무인 매장 / Just-Walk-Out 관련 연구 (Amazon Go 계열, 그룹 추적, 상품-고객 연결)
- [ ] 낙상 감지(fall detection) 연구 — 후보 ③은 **오탐률을 앞세운 차별화**가 필요하다.
      정확도 경쟁으로 가면 딥러닝 기반 SOTA에 밀린다
- [ ] Multi-camera person association / 사각지대 하의 tracklet 연결
- [ ] 프라이버시 보존 영상 분석 (de-identification, on-device inference)
- [ ] 무인 매장 이상행동 감지 국내 선행연구
