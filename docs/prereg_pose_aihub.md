# 포즈 파인튜닝(AI-Hub 관절 정답) — 사전 등록 (학습 전 고정, 2026-11-07)

> **데이터 출처**: AI-Hub 「실내(편의점, 매장) 사람 이상행동 데이터」(과학기술정보통신부·한국지능정보사회진흥원 「지능정보산업 인프라 조성」 사업의 결과물). 이 문서와 이후 결과 문서는 그 2차적 저작물이다. 이용 범위(학습 모델의 상업 탑재 포함)는 AI-Hub 회신으로 확인했다고 사용자가 전했으나 회신 원문은 아직 저장소에 없다([README](../README.md#평가-데이터-출처-ai-hub)) — 배포 전에 보관해야 한다. 프레임(가공본 포함)은 AI 도구로 열지 않는다.

근거: [진단](pose-aihub-gt-diagnosis-2026-11-07.md) — 배포 포즈 모델은 쓰러진 사람에서 PCK 0.46(서 있는 사람 0.89), 점수 ≥ 0.5 비율 0.66(0.99).

## 고정 사항
**데이터** (`scripts/finetune_pose_aihub.py`)
- AI-Hub **pool 분할 장면만**: 전도(07) 관절 프레임 4장에 1장, 폭행(13)·파손(08) 11장에 1장(서 있는 사람 대조군). 사람 박스 = 관절 외곽 + 15%, 얼굴 5점 v=0.
- COCO 일반 포즈 12,000장(`datasets/pose_original_12000` 학습 목록)을 그대로 섞는다.
- dev 는 전후 진단 전용(학습 금지), test 는 쓰지 않는다.

**학습**: 시작 가중치 `yolo11n-pose.pt`(배포 모델의 원본), 하이퍼파라미터는 `finetune_pose_original.py` 와 같게 고정(AdamW lr 5e-5, 12에폭, patience 4, imgsz 416 rect, 시드 4300). **탐색 없음, 1회 학습.** best.pt 를 416×224 ONNX 로 내보낸다(C 측 변경 없음).

## Go / No-Go (사전 고정)
| 기준 | 기준값 | 비교 대상(현재 모델) |
|---|---|---|
| dev 전도·누움 PCK@0.1 | **≥ 0.60** | 0.459 |
| dev 전도·누움 점수 ≥ 0.5 비율 | **≥ 0.75** | 0.657 |
| dev 서 있는 사람(13·08 세로) PCK 하락 | **≤ 0.02** | 0.887 / 0.904 |
| dev 서 있는 사람 점수 ≥ 0.5 하락 | **≤ 0.01** | 0.985 / 0.992 |
| COCO held-out 포즈 mAP50 하락 | **≤ 2pt** | 원본 모델 같은 평가 |
| 쓰러짐 룰 dev(현장 설정, 장면당 1클립 48) 재현율 | 현재 이상 | 12/48 |
| 같은 설정 음성(dev 클래스당 30) 오탐 | 현재 이하(0) | 0 |

하나라도 못 넘으면 No-Go 로 기록하고 배포 모델은 바꾸지 않는다. Go 여도 출시 프로파일의 모델 교체는 매장 영상 확인 뒤에 한다.

## 미리 적는 한계
- pool 장면으로 포즈를 학습하면 **이 모델로 재는 pool 쓰러짐 평가는 더 이상 깨끗하지 않다**(같은 장면의 다른 카메라·프레임을 봤음). 이후 비교는 dev 와 매장 그림자 운영으로만 한다.
- 라벨 없는 주변 사람은 배경으로 학습된다 — COCO held-out 과 dev 대조군으로 퇴화를 잰다.
- 관절 매핑이 근사(손→손목, 발→발목)라 모델이 손목·발목 위치를 손끝·발끝 쪽으로 옮겨 배울 수 있다.
- i5-4200U 지연은 구조가 같아 변하지 않는다(같은 YOLO11n-pose, 같은 입력 크기).

## 변경 이력
- 2026-11-07 최초 작성(학습 전).
- 2026-11-07 **1차 학습 No-Go**: COCO held-out 포즈 mAP50 0.739 → 0.553(−18.6pt, 기준 ≤ 2pt), 박스 mAP50-95 0.676 → 0.340.
  원인은 라벨 변환 버그 — 사람 박스를 COCO 로 매핑되는 관절만으로 만들어 **머리(Center head)가 박스 밖**(목까지)이었다.
  COCO 박스는 머리를 포함하므로 모델이 머리 없는 박스를 배워 COCO 에서 IoU 가 무너졌다. dev 지표는 재지 않았다(기준 하나로 이미 No-Go).
  수정: 박스 외곽에 Center head 를 포함(관절로는 여전히 쓰지 않음). 프레임·분할·하이퍼파라미터·Go 기준은 그대로 두고 **한 번만** 다시 학습한다.
  2차도 No-Go 면 이 방향은 중단하고 기록한다. 1차 결과: `runs/pose/pose-aihub-finetune-run1-nogo/heldout-comparison.json`.
