## 구현 완료

### 1. 초과 체류 `overstay`

- **방식**: YOLO Tier 1(사람 감지) + 추적기로 개인별 체류 시간 누적
- **발화**: 단일 트랙 체류 시간 > `dwell_limit_seconds` (기본 3,600초)
- **래치**: 조건 지속 중 1회만 발화, 퇴장 시 해제
- **한계**
  - 화면 밖으로 나갔다 돌아오면 새 트랙 ID → 체류 시간 리셋
  - 멀티카메라 환경에서 동일인 연속 추적 불가

---

### 2. 미주문 착석 `unordered_seated`

- **방식**: 트랙의 주문 상태(`UNORDERED`) + 유예 시간 경과
- **발화**: 주문 미확인 상태로 `unordered_grace_seconds` (기본 300초) 초과
- **주문 인식**: 키오스크 ROI 내에 사람 중심점이 들어오면 `ORDERED`로 전환
- **한계**
  - **ROI 미설정 시 전원 미주문으로 오탐** — 반드시 설정 필요
  - 실제 결제 여부(카드 단말기 등)와 연동 없음
  - 배달 앱·셀프 주문 방식은 판단 불가

---

### 3. 쓰러짐 `person_fallen`

- **방식**: YOLO11 pose 모델 + 기하 조건
- **발화**: 아래 조건이 `fall_hold_seconds` (기본 5초) 이상 지속
  - keypoint 있음: bbox 가로/세로 비 ≥ 1.8 + 머리·어깨·엉덩이 y 표준편차/bbox높이 ≤ 0.20 + 엉덩이 keypoint 유효
  - keypoint 없음: bbox 가로/세로 비 ≥ 2.2
- **래치**: 수직 자세 복귀 시 즉시 해제
- **한계**
  - 바닥 청소·물건 줍기 등 5초 이상 수평 자세 유지 시 오탐
  - 카메라 높이·각도에 따라 bbox 비율 조건의 유효성이 크게 달라짐

---

### 4. 외부 음료 반입 `external_drink`

- **방식**: Tier 2 YOLO 파인튜닝, `bottle` 클래스 감지
- **발화**: 화면 내 bottle 감지 시 이벤트 발화 (1회, 조건 해소 후 재발화 가능)
- **한계**
  - 캔·텀블러·파우치 음료 미감지
  - 매장 내 판매 음료와 외부 반입 음료 구분 불가
  - 선반·진열대 위 병도 오탐 가능

---

### 5. 외부 음식 반입 `external_food`

- **방식**: Tier 2 YOLO, COCO 음식 10개 클래스 감지 (banana, apple, sandwich, pizza, donut, cake 등)
- **발화**: 해당 클래스 감지 즉시
- **한계**
  - 컵라면·도시락·김밥·편의점 음식 미감지
  - 매장 내 판매 케이크·쿠키 있으면 오탐 유발 가능

---

### 6. 반려동물 의자 착석 `animal_on_chair`

- **방식**: Tier 2, cat/dog bbox와 chair bbox의 IoU ≥ 0.15
- **발화**: IoU 조건 충족 즉시 (1회)
- **한계**
  - IoU 0.15는 낮은 기준 → 의자 근처 지나쳐도 반응 가능
  - 소형견과 대형견의 크기 차이로 동일 기준의 일관성이 낮음

---

### 7. 반려동물 테이블 착석 `animal_on_table`

- **방식**: Tier 2, cat/dog bbox와 dining table bbox의 IoU ≥ 0.15
- 6번과 동일한 한계

---

### 8. 1인 1음료 미구매 착석 `no_cup_seated`

- **방식**: Tier 2 cup 감지 수 vs 활성 사람 트랙 수 비교
- **발화**: `active_persons > cup_count + no_cup_margin` (기본 margin=1)
- **한계**
  - cup 클래스는 손잡이 있는 컵 위주 → 뚜껑 씌운 테이크아웃 컵·캔 미인식
  - 컵이 테이블 아래 또는 가방에 가려진 경우 미감지
  - margin=1이므로 2인석에 컵 1개만 보여도 발화

---

### 9. 잔류물 감지 `residue_trash` / `residue_spill` / `residue_cleared`

- **방식**: 배경 차분 — 청결 기준 이미지 대비 블록 단위 휘도 차 + 지속 시간 확인
- **발화**: 사람 bbox 외 영역에서 diff ≥ `residue_diff_threshold`(기본 18) 블록이 `min_blocks`(기본 3개) 이상 연결되어 `confirm_seconds`(기본 60초) 지속
- **분류 기준**: 가구 bbox 안 중심점 → `trash`, 바닥 → `spill`, Tier 2 미실행 → `unknown`
- **한계**
  - **기준 이미지 미캡처 시 완전 비활성** — 설치 시 반드시 캡처 필요
  - 의자 위 가방·짐도 `trash`로 분류 (미결)
  - 점진적 조명 변화(일몰 등)에 취약 (급격한 변화는 global_change_ratio로 방어)
  - 최대 8개 영역 동시 추적

---

### 10. 문 장기 개방 `door_open` / `door_closed`

- **방식**: 픽셀 차분 — 닫힘/열림 기준 이미지 2장과 현재 프레임 비교
- **발화**: 열린 상태가 `door_open_seconds`(기본 30초) 이상 유지
- **판정**: 기준 이미지 2장 모두 있으면 거리 비교(조명 변화에 강인), 닫힘 기준만 있으면 단일 임계값 방식
- **한계**
  - **기준 이미지 없으면 비활성** — 설치 시 열림·닫힘 2장 캡처 필요
  - ROI 미설정 시 전체 화면 비교 → 사람 움직임에도 반응
  - 반쯤 열린 상태의 분류가 불명확

---

### 11. 카메라 장애 `camera_whiteout` / `camera_blackout` / `camera_frozen`

- **방식**: 통계 기반 — 프레임별 평균 luma, 변화 픽셀 비율
- **발화**
  - 백화: 평균 luma > `luma_white_threshold`(기본 240) 연속 5프레임
  - 암전: 평균 luma < 12 연속 5프레임
  - 정지: 변화 픽셀 비율 ≈ 0이 `frozen_frames_threshold`(기본 150프레임 ≈ 5초) 연속
- **한계**: 매우 정적인 정상 장면과 정지 구분이 어려울 수 있음

## 미구현 (설계·목표에만 존재)

| 기능 | 현재 상태 | 이유 |
|---|---|---|
| 시럽 과다 복용 / 구토 | 미구현 | 데이터셋 없음, 감지 방식 미정 |
| 노키즈존·출입 제한 대상 진입 | 미구현 | 나이 추정 모델 필요 |
| 기물 파손 | 미구현 | 이벤트 정의 없음 |
| 매장 판매 음료 vs 외부 음료 구분 | 구조적 불가 | 클래스 미분리 |
| 멀티카메라 동일인 추적 | 미구현 | 카메라 간 ID 매핑 로직 없음 |
| 응급상황 (실신 판별 고도화) | 부분 구현 | 현재는 기하 조건만, 의식 여부 판단 불가 |
