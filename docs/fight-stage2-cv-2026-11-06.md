사전 등록([prereg_fight_stage2.md](prereg_fight_stage2.md))의 규칙대로 dev+pool 합본에서 **매장 단위 leave-one-store-out(7개 매장)** 교차검증을 했다. **이 문서는 test를 열기 전에 작성했다.** test 결과를 본 뒤에는 모델·임계값을 바꾸지 않는다.

## 데이터

## Go / No-Go 판정 (사전 등록 기준)

| 기준 | 값 | 결과 |
|---|---|---|
| 교차검증 합산 클립 재현율 ≥ 0.75 | **0.870** (임계값 0.984) | 통과 |
| 같은 임계값에서 오탐 ≤ 2.0 건/시간 | **1.94** (13건 / 6.69시간) | 통과(경계) |
| 매장별 최저 재현율 ≥ 0.50 | **0.667** (SMC) | 통과 |
| 1차 필터 단독 대비 오탐이 더 적을 것 | 같은 재현율(≥0.87)에서 기준선 20.0 건/시간 | 통과(아래 주의) |
| 모델 크기 < 100KB, 지연 < 2 ms/창 | **90.7 KB**, **0.05 ms**(개발 PC, 1스레드) | 통과 |

→ 사전 등록 기준으로는 **Go**.

매장별 재현율: DYA 0.863 · DYB 0.928 · SMA 0.877 · SMB 0.935 · SYB 0.905 · **SYA 0.691 · SMC 0.667**(새 매장 일반화가 약한 두 곳).

## 주의 (읽을 때 꼭 고려)
- **오탐 기준은 경계값이다.** 임계값을 "오탐 ≤ 2.0/시간을 만족하는 가장 낮은 값"으로 정했으므로 1.94는 구조상 상한 근처에 놓인다. 13건 / 6.69시간의 포아송 95% 상한은 약 3.3건/시간이라, "2.0 이하"를 통계적으로 보장하는 값이 아니다. 음성 시간이 짧아 카페 규모 오탐률은 **미측정**이다.
- **기준선 비교는 근사다.** 사전 등록은 1차 필터(`fight_score`)를 기준선으로 했지만, 창 데이터에는 팔다리 속도가 없어 "창 안 최대 쌍 근접도 × 정규화 관절 변위"로 근사했다. 근사 기준선은 이 오탐 한도(2.0)에서 재현율이 0.003으로 사실상 못 쓰는 수준이라, 실제 `fight_score`(1단계 측정에서 엄격 TPR 0.844)와 직접 같은 조건은 아니다. 2차 AI가 1차 필터보다 나은지는 **test 이후 같은 규칙(연속 4창 중 2창)으로 실제 `fight_score`와 다시 비교**해야 확정된다.
- **모델 선택과 임계값이 같은 교차검증 예측에서 정해졌다**(3개 중 선택 + 임계값). 약간 낙관적이다. 그래서 test를 한 번만 쓴다.
- 최종 모델은 전체 데이터로 다시 학습했으므로 확률 분포가 교차검증 때와 조금 다를 수 있다(임계값 0.984가 그대로 맞는지는 test에서 드러난다).
- 연출 3fps, 배우 1~2명, 매장 7곳. 같은 배우·시나리오가 매장 사이에 겹친다. 평상시 대화·악수·포옹·아이 놀이 같은 일반 음성은 이 데이터에 거의 없다.
- i5-4200U 지연·CPU는 미측정이다(개발 PC 0.05 ms는 순수 ONNX 추론이고 창 특징 계산 비용은 포함하지 않는다).
