# 촬영 영상 23개: 1차 자료 적합성 평가

## 결론과 범위

현재 자료로 개발용 예비 평가를 시작할 수 있다. 남은 50개 시나리오 촬영을 먼저 끝낼 필요는 없다. 다만 이번에 완료한 것은 **파일·시각·대표 장면의 자료 적합성 점검**이며, 감지기 추론을 실행한 정확도 평가가 아니다. TP/FP/FN·F1·알림 지연·CPU·추론 절감률은 아직 산출하지 않았다.

원본 폴더: `records/session-2026-09-11T07-12-10-284Z-7d0c50b3/`

검토 결과 폴더: `runs/record-audit-6l5Wca/`. 원본 영상·원본 메타데이터와 운영 설정은 변경하지 않았다. 추가 촬영·학습·감지기 재시작도 하지 않았다.

## 검사 방법

1. 세션 기록·영상 목록·개별 JSON을 대조했다.
2. ffprobe로 코덱·해상도를 읽고 전체 비디오 패킷의 PTS를 검사했다.
3. 각 영상에서 초기 20초, 행동 카운트다운 시작+15초, 관찰 시작+10초, 관찰 시작+75초, 종료 약 3초 전 화면을 추출했다.
4. 초기·관찰 후반·종료의 테이블 확대 비교 시트를 6장 만들고 육안 검토했다. S17·S38은 관찰 초반 전체 화면도 추가 확인했다.

지정 시점 디코딩이 성공했다고 영상 전체가 완전 디코딩 검증된 것은 아니다. 순간 접촉·일시 부재·정확한 배치/퇴석 시각은 5장으로 확정하지 않는다. 추출 요청 시각은 프레임 PTS의 정확한 주석이 아니므로 정밀 지연 평가에 그대로 쓰지 않는다.

## 평가 전에 처리할 문제

### 1. 녹화에는 예측 로그가 없다

JSON의 `prompts`는 안내 시각이다. 감지기 예측, 사람 점유 판정, 실제 알림 onset, 실제 AI 실행 횟수가 아니다. 따라서 시나리오 이름만으로 모델 정확도를 계산할 수 없다.

### 2. 현재 파일 재생의 시계

`src/main.c`의 프레임 처리와 `surface_process()`는 `platform_monotonic_seconds()`를 사용하고 AI 결과 제출에도 같은 실행 시계를 사용한다. 파일 입력을 빠르게 처리하면 실제 영상의 45초 퇴석 유예를 동일하게 재현한다는 보장이 없다. 운영 감지기 설정을 수정하지 않고, 분리된 평가 경로에서 영상 PTS 기반 정책·결과 시각·초기화를 검증해야 한다.

### 3. 기준 장면 및 ROI

현재 운영 설정은 `config/surfaces.json` revision 5이지만 녹화 세션에 해당 설정과 기준 이미지가 동결 저장되어 있지 않다. 지금 설정이 촬영 당시 정답 설정과 동일하다고 확정할 수 없다. 앞쪽 테이블의 실제 화각에 맞춰 평가용 설정 복사본을 검토하고, 깨끗한 영상 구간에서 평가용 기준을 만든다. 특히 S38은 초기 20초를 무조건 정상 기준으로 사용하지 않는다.

### 4. 프레임 시간 불연속

전체 패킷 검사에서 100ms 초과 간격 4건, 증가하지 않는 PTS 간격 1건이 있었다. 최대 간격은 약 1.267초다. 위치·대상 파일별 수치는 `timestamp-audit.json`에서 확인한다. 명목 30fps를 근거로 `프레임 번호/30`만 사용하면 실제 시각과 어긋날 수 있다. 패킷 이상만으로 곧바로 파일 전체를 폐기하지 않는다.

### 5. 촬영 조건

대표 전체 화면에 뒤쪽 사람이 보인다. 주 시험 참여자가 한 명이어도 화면 전체의 사람이 항상 한 명인 것은 아니다. 테이블 이용 구역으로 제한한 평가와 배경 사람에 따른 영향·얼굴 비식별을 기록한다. 의자 위치도 클립 사이에 달라진다. 이것은 배치 변화 조건이며 정답 박스·가림 판정에서 고려한다.

## 다음 평가 단계 — 추가 촬영 없이

1. 현재 23개를 보존하고 S17·S38 및 짧은 동작의 실제 수행을 원본으로 확인한다.
2. 실제 배치·최종 퇴석·가림 해제·제거 시각을 영상 PTS로 주석한다. 불명확한 정답은 보류하며 임의로 채우지 않는다.
3. 분리된 오프라인 평가기로 기준·ROI를 적용하고 영상 시간 기준 정책을 검증한다.
4. 동일 영상에 현행 방식과 재사용 OFF/ON을 실행하고 사건별 대응 결과를 만든다.

이 자료는 같은 테이블의 첫 개발용 세트로 취급한다. 이 영상을 보면서 규칙을 조정한 뒤 동일 영상 결과를 독립 최종 테스트 성능처럼 보고하지 않는다. 현재 단계에서 추가 촬영을 요구하지 않는다.
