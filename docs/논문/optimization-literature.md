# 최적화 관련 논문과 현재 구현의 연결

이 문서의 번호는 IMRaD 초안의 참고문헌 번호와 같다. 서로 다른 작업·데이터·장치의 성능 수치를 직접 비교하지 않는다. 조사한 방법을 구현했다는 의미도 아니다.

| 논문 | 핵심 방법 | 현재 시스템과 연결 | 현재 미구현 부분 |
|---|---|---|---|
| [3] NoScope, PVLDB 2017 | 영상 차이 검사와 특화 모델 캐스케이드 | 저렴한 규칙으로 비싼 모델 호출을 줄이는 설계 근거 | 특화 모델 학습, 비용 기반 자동 탐색 |
| [4] DeepCache, MobiCom 2018 | 연속 영상에서 모델 내부 계산 재사용 | 시간적 유사성과 재사용 유효성 검사의 필요성 | 신경망 내부 특징 재사용, 런타임 변경 |
| [5] FrameExit, CVPR 2021 | 학습된 게이트로 프레임 처리의 조기 종료 | 장면에 따라 계산량을 조절하는 후속 방향 | 학습형 게이트, 클립 수준 조기 종료 |

## 1. 가장 직접적으로 연결되는 NoScope

영상이 거의 같을 때 매번 전체 모델을 실행할 필요가 없다는 문제 설정이 현재 작업과 연결된다. 다만 현재 코드는 미리 정한 차이·IoU 임계값과 캐시 정책이며, NoScope의 모델 검색·학습 파이프라인을 재현하지 않았다. 논문에는 ‘NoScope와 같이 시간적 중복을 줄이는 관점에서 출발하되, 본 시스템은 표면 후보와 이용 상태에 기반한 검사 제어를 사용한다’고 쓸 수 있다. [학회 원문](https://www.vldb.org/pvldb/vol10/p1586-kang.pdf)

## 2. DeepCache와 구분해야 할 점

DeepCache는 영상 유사성을 모델 내부 재사용 영역으로 전파한다. 현재 코드는 네트워크 중간 텐서를 재사용하지 않고 **최종 검사 결과를 재사용하여 전체 호출을 생략**한다. 따라서 ‘DeepCache 적용’이 아니라 ‘시간적 지역성을 활용한 재사용 연구와 관련된 접근’이라고 표현한다. 저자의 성능 수치를 우리 코드의 예상 효과로 인용하지 않는다. [저자 원문](https://xumengwei.github.io/files/MobiCom18-DeepCache.pdf)

## 3. FrameExit는 향후 확장 근거

FrameExit는 간단한 영상에는 적은 프레임, 복잡한 영상에는 더 많은 프레임을 처리하도록 학습한다. 현재 모니터는 지속 감시이므로 클립 분류처럼 처리를 영구 종료할 수 없다. 적용을 검토한다면 ‘조용할 때 검사 주기를 늘리되 새 사람·새 변화에는 즉시 복귀’하는 방식으로 안전 감사·최대 지연을 별도 설계해야 한다. 이는 현재 구현되지 않은 연구 방향이다. [학회 원문](https://openaccess.thecvf.com/content/CVPR2021/html/Ghodrati_FrameExit_Conditional_Early_Exiting_for_Efficient_Video_Recognition_CVPR_2021_paper.html)

## 논문에 넣을 짧은 문장

> 영상 분석의 반복 계산을 줄이기 위해 차이 검출과 모델 특화를 결합한 NoScope[3], 모델 내부 결과를 재사용하는 DeepCache[4], 프레임 처리량을 조절하는 FrameExit[5]가 제안되었다. 본 시스템은 모델 내부 구조를 변경하지 않고 표면 후보의 위치·모습 및 이용 상태에 따라 검사 결과를 재사용한다.

2페이지 분량이 부족하면 [3]과 [4]를 본문에서 우선 설명하고, [5]는 후속 연구 논의에 한 문장으로 배치할 수 있다. 7편이라는 개수보다 각 인용이 실제 문장을 뒷받침하는지가 중요하다.

## 우리 시스템에서 측정할 것

- 동일 입력 OFF/ON의 실제 AI 실행 수와 요청 수를 분리한다.
- 차이·캐시 확인에 추가된 시간도 측정하여 순절감인지 확인한다.
- 후보가 움직이거나 비슷한 물체로 바뀔 때의 누락·재검사 지연을 함께 측정한다.
- CPU·에너지 절감을 주장하려면 해당 장치의 실제 값을 측정한다. 현재 9→1회 합성 결과만으로는 부족하다.
- 현재 사용 중인 감지기에서 `ai_scheduler`가 누락되면 최신 바이너리를 적용한 뒤 경량화 비교를 시작한다.
