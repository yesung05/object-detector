# S18 재추론 마스크 그림 설명

대표 그림: `s18-surface-mask-pipeline.png`

재추론 조건은 선택 설정인 RGB 차이 임계값 32, 최소 변화 면적 비율 0.003, 확인시간 15초이다. 알림은 영상 시각 89초에 시작되었고 표면 사건 시각은 90초였다. 표면 ROI 4,718셀 중 임계값을 넘은 셀은 213개였으며, 연결영역 필터 후 200개가 두 후보 영역(111셀, 89셀)으로 남았다.

논문용 캡션 후보:

> 그림 X. S18 영상의 표면 변화 후보 생성 과정. (a) 원본과 표면 ROI 및 검출 후보, (b) 기준 표면, (c) RGB 임계값을 넘은 변화 마스크, (d) 최소 연결영역 필터를 통과한 후보 마스크.

해석상 주의:

- 이 마스크는 코드가 예측한 변화 후보이지 사람이 작성한 정답 마스크가 아니다.
- 현재 평가는 사건 단위 알림 유무를 판정하며 후보 영역과 실제 잔류물의 공간 일치도를 평가하지 않는다.
- 따라서 이 그림을 “휴대전화 위치를 정확히 분할한 결과”로 설명하면 안 된다. 파이프라인의 중간 결과 예시로만 사용한다.
