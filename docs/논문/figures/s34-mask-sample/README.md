# 논문용 권장 마스크 샘플: S34

시나리오: 가방 뒤에 종이를 남기고 가방만 가져감  
대표 그림: `s34-surface-mask-pipeline.png`

S34를 권장하는 이유:

- 원본 영상의 남겨진 종이와 빨간 변화 후보의 위치가 시각적으로 대응한다.
- RGB 임계값 적용 후 57셀이 검출되었고, 연결영역 필터 후에도 하나의 영역 57셀이 그대로 남았다.
- S40과 S25처럼 테이블 왼쪽 경계의 큰 변화 영역이 함께 남지 않아 처리 단계를 설명하기 쉽다.
- 최종 선택 설정에서도 양성 시나리오를 올바르게 알린 TP 사례다.

논문용 캡션 후보:

> 그림 X. S34 시나리오의 표면 변화 검출 과정. (a) 퇴장 후 원본 영상과 표면 ROI 및 변화 후보, (b) 정상 기준 표면, (c) RGB 차이 임계값을 적용한 변화 마스크, (d) 최소 연결영역 필터를 통과한 최종 후보. 임계값 32와 최소 면적 비율 0.003을 적용했으며, 후보가 15초간 유지된 뒤 알림이 발생하였다.

주의:

- 빨간 영역은 코드가 생성한 변화 후보이며 사람이 작성한 픽셀 단위 정답 마스크가 아니다.
- 현재 평가는 사건 단위 알림 유무를 판정했으며 마스크 IoU나 분할 정확도를 측정하지 않았다.
- 따라서 “종이를 정확히 분할했다”보다 “종이와 대응하는 지속 변화 후보를 생성했다”고 설명한다.
