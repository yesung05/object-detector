# IMRaD 초안 편집 및 제출 전 확인 사항

본문은 [draft-imrad.md](draft-imrad.md)에 있다. 회사명, 가상의 저자·소속, 확인하지 않은 외부 인용은 넣지 않았다. 이 문서는 본문에 포함하지 않는 작성자용 메모다.

## 구성

- Introduction: 운영 문제, 감시 범위, 연구 목적.
- Methods: 실제 구현 정책, 모델 검사와 규칙 알림의 관계, 합성 비교 조건.
- Results: 관측된 9→1회와 회귀 검증만 보고.
- Discussion: 해석, 실환경 일반화의 한계, 후속 평가.

실영상 평가가 아직 없으므로 제목을 ‘구현 및 예비 평가’로 설정했다. 핵심 주제는 무인 매장 환경·위생 관리이며, AI 재사용은 방법의 일부다. 결과 절에서 실측한 것과 논의 절에서 기대하는 효과를 구분했다.

## 2페이지 편집

학회 양식이 제공되지 않아 실제 2페이지 적합 여부는 아직 확인하지 않았다. 현재 문서는 편집용 초안이며 학회의 글자 크기·단 수·참고문헌 포함 여부에 맞춰 줄여야 한다.

우선 전체 구조도 1개와 결과 표 1개를 사용한다. UI 캡처가 필수라면 구조도를 간단히 줄이거나 그림을 하나만 선택한다. 초록은 약 4~6문장으로 유지하고, 방법의 상세 임계값은 필요 시 구현 문서로 옮긴다. 결과의 ‘테스트 대역·미측정’ 설명은 분량 때문에 삭제하지 않는다.

## 필수 보완

1. 학회 양식에 맞춘 저자·소속·연락처를 실제 정보로 기입한다. 익명 심사이면 해당 규정을 따른다.
2. 서론과 참고문헌에 최적화 3편을 포함한 총 7편을 추가했다. [관련 연구 기록](related-work.md)과 [최적화 해설](optimization-literature.md)의 인용 범위·차이를 확인하고, 무인 매장 청결 감시의 직접 선행연구도 추가 조사한다. 선행연구보다 우수하거나 최초라는 주장은 하지 않는다.
3. 실제 모델 기반 성능을 결과에 추가하면 모델 명칭·버전·입력 크기·양자화·추론 공급자·스레드 수·장치 사양을 명시한다. 현재 합성 결과는 모델을 실행하지 않았으므로 특정 모델의 성능 결과처럼 표시하지 않는다.
4. 실제 영상 사건 실험을 추가하고 사건 수·정답 정의·알림 매칭 시간창·관측 불가 비율을 보고한다. [추천 실험](recommended-tests.md)을 따른다.
5. 합성 시험의 퇴석·잔류 시간은 각각 2초이며 운영 기본값 45초·15초와 다르다. 본문의 구분을 유지한다.
6. UI 캡처의 누적 카운터를 합성 결과 표와 혼동하지 않는다. 촬영 시각·상태를 기록하고, 얼굴·상호·주소를 공개 전 점검한다.
7. 본문의 주장과 최종 실험 커밋·설정·원자료가 일치하는지 확인한다. 동일 입력 9→1회는 실제 자원 88.9% 감소를 뜻하지 않는다.
