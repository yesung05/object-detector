# 논문에 넣을 수치·다이어그램 가이드

## 1. 현재 검증된 수치

| 항목 | 값 | 성격 |
|---|---:|---|
| 비교 입력 | 100×100 합성 RGB, 50초 관측 구간 | 테스트 조건 |
| 규칙 비교 크기 | 표면별 96×96 | 구현 설정 |
| 테이블·바닥 관측 간격 | 최소 0.5초 | 구현 설정, 실제 FPS 측정 아님 |
| 벽 관측 간격 | 최소 2초 | 구현 설정 |
| 전체 AI 요청 상한 | 초당 최대 1회 | 스케줄러 설정 |
| 동일 정적 후보 요청, 재사용 OFF | 9회 | 합성 테스트 관측값 |
| 동일 정적 후보 요청, 재사용 ON | 1회 | 합성 테스트 관측값 |
| 후보 요청 감소율 | 88.9% | (9−1)/9×100 |
| 실제 CPU·전력·FPS 개선 | 미측정 | 논문에 임의 수치 금지 |
| 실영상 사건별 precision/recall | 미측정 | 추가 실험 필요 |

재현 프로그램은 `tests/test_surface.c`의 `scheduler_scenario`다. 배경 RGB 값은 80이며 4초부터 같은 위치에 값 180의 사각형을 추가한다. 0.5초 간격으로 관측하며, AI는 동물을 반환하지 않고 성공하는 테스트 대역이다. 일반 알림은 두 조건 모두 발생한다. 이 구간에서는 60초 주기의 전체 표면 감사가 발생하지 않는다.

논문에 사용 가능한 표현:

> 정적 잔류 후보를 유지한 50초 합성 입력에서, 후보 AI 검사 요청은 주기 검사 9회에서 결과 재사용 적용 시 1회로 감소하였다. 이는 스케줄링 동작의 예비 검증이며 실환경 정확도 및 자원 절감률은 별도 평가가 필요하다.

사용하면 안 되는 표현:

- ‘시스템 CPU 사용량이 88.9% 감소했다.’
- ‘쓰레기 검출 정확도 100%를 달성했다.’
- ‘실제 매장에서 추론 비용을 평균 88.9% 절감했다.’

## 2. 그림 자료

### 전체 구조도

[architecture.svg](architecture.svg): 규칙 비교와 사람·가림 상태, 선택적 AI, 알림을 나타내는 벡터 그림이다. 회사명이나 제품 로고는 없다. 문서 편집기에 SVG로 넣으면 확대 시 글자가 선명하다.

> 그림 1. 무인 매장의 환경·위생 관리를 위한 표면 변화 기반 감시 구조. 청소 확인 알림은 규칙 근거로도 발생하며 AI는 후보 검사와 동물 확인을 보조한다.

### 테이블 상태 정책

[table-policy.svg](table-policy.svg): 이용 중 보류, 퇴석 후 확인, 가림 시 판정 보류를 나타낸다.

> 그림 2. 이용자와 가림을 고려한 테이블 청소 확인 정책. 가림은 청소 완료로 해석하지 않으며, 동물 의심은 일반 청소 알림 보류의 예외로 확인한다.

2페이지에서는 두 구조도를 모두 넣기보다 전체 구조도와 실제 결과 표를 우선 권장한다. UI 캡처가 필요하면 구조도를 작게 하거나 후속 발표 슬라이드에 배치한다.

## 3. 추천 결과 표 틀

| 장면 | 방법 | 사건 검출/전체 | 오탐 수 | 알림 지연 p50/p95 | AI 실행/분 | CPU 평균 |
|---|---|---|---|---|---|---|
| 정상 비치물 | 주기 검사 / 재사용 | 측정 후 입력 | 측정 후 입력 | 해당 없음 또는 측정 | 측정 후 입력 | 측정 후 입력 |
| 퇴석 후 잔류 | 주기 검사 / 재사용 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 |
| 가림 중 물체 추가 | 주기 검사 / 재사용 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 |
| 정적 잔류물 | 주기 검사 / 재사용 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 | 측정 후 입력 |

‘해당 없음’과 0을 구분한다. GT 사건이 없는 정상 영상에서 recall을 100%로 쓰지 않는다. p95는 사건 수가 작으면 불안정하므로 사건 수와 개별 지연도 함께 보관한다.

## 4. 별도 대시보드 값으로 할 수 없는 평가

화면의 재사용 관측 수만으로 요청 절감률을 계산할 수 없다. 같은 영상의 OFF/ON 총 요청 수를 비교해야 한다. 실제 실행 수는 감지기의 추론 계측에서 별도로 얻는다. 2초 주기 화면 수신 시각은 사건의 실제 발생/알림 시각과 다르므로 지연 계산에 사용하지 않는다.

요청 감소율은 `100 × (N_OFF − N_ON) / N_OFF`이며 N_OFF가 0이면 정의하지 않는다. 서로 다른 길이의 영상이면 요청/분으로 정규화하되 장면 구성도 함께 보고한다.
