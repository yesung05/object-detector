# 2페이지 논문을 위한 추천 실험

## 1. 목표

주요 목표는 ‘무인 매장의 오염·잔류 의심 상황을 정상 비치물 및 사람 활동과 구분하여 알리는가’이다. 효율화는 보조 목표다. 호출이 적다는 이유만으로 좋은 시스템이라고 결론 내리지 않는다. 감지 누락·오탐·알림 지연을 함께 측정한다.

아래 장면 수·반복 수는 이 프로젝트의 실행 가능한 출발점 제안이며, 학회가 요구하는 공식 최소 기준이나 통계적 충분성 보장이 아니다.

## 2. 우선 수행할 장면

| ID | 장면 | 기대 동작 | 주요 측정 |
|---|---|---|---|
| S1 | 평소 컵·휴지통·모니터가 있는 깨끗한 매장 | 지속 청소 알림 없음 | 시간당 오탐 |
| S2 | 바닥에 종이·빈 용기 등 잔류물 추가 | 변화 지속 후 청소 확인 알림 | 사건 recall, 지연 |
| S3 | 사람이 테이블에서 컵 사용 후 가져감 | 이용 중 청소 알림 보류, 떠난 뒤 잔류 알림 없음 | 이용 중 오탐 |
| S4 | 사람이 컵·쓰레기를 남기고 퇴석 | 퇴석 유예 후 지속 변화에 알림 | 퇴석 후 recall·지연 |
| S5 | 사람이 가린 동안 새 물체를 놓고 비킴 | 가림 중 정상으로 해제하지 않으며 다시 보인 뒤 확인 | 가림 해제 후 recall·지연 |
| S6 | 같은 위치에서 비슷한 색/다른 색 물체 교체 | 필요한 재검사, 이전 결과의 잘못된 재사용 확인 | 캐시 오재사용 사례 |
| S7 | 조명 켜고 끄기·그림자·작은 카메라 흔들림 | 품질 이상/확인 보류, 불필요한 오염 확정 억제 | 품질 보류율, 오탐 |
| S8 | 알림 후 물체 제거, 일부/전체 가림 포함 | 충분히 다시 보인 뒤 알림 해제 | 조기 해제 오류, 해제 지연 |

벽 오염을 다룬다고 주장하려면 별도 벽 장면을 넣는다. 실제 오염 대신 안전하게 붙였다 제거할 수 있는 무광 색지 등을 사용할 수 있으나 ‘모사 오염’이라고 명시한다. 바닥/테이블의 소량 액체 모사는 전자기기·전원에서 떨어진 방수 트레이 등 안전한 환경에서만 수행한다. 배설물·토사물 세부 분류 실험처럼 표현하지 않는다.

동물 기능을 논문 성능 주장에 포함할 때만 S9(동물 진입, 사람이 함께 있음)을 추가한다. 통제되고 적법하게 확보한 영상을 사용한다. 동물 모형을 실제 동물 검출 성능의 근거로 쓰지 않는다. 동물을 테이블에 올리는 등 불필요한 스트레스를 주는 촬영은 피한다.

## 3. 권장 규모와 촬영 조건

- 1차: S2~S6, S8을 각각 독립된 사건 10회 정도부터 수집하고, 정상 영상 S1은 합계 30분 이상부터 시작한다.
- 가능하면 카메라 구도/거리 2개, 조명 조건 2개로 확대한다.
- 장면마다 같은 클립을 반복 재생한 횟수와 독립적으로 촬영한 사건 수를 분리한다. 같은 사건 10회 재생을 사건 10개로 계산하지 않는다.
- 정상 비치물, 작은 물체, 배경과 색이 비슷한 물체를 포함한다. 쉬운 예시만 선별하지 않는다.
- 각 클립은 퇴석 유예·확인 시간·해제 시간을 포함할 만큼 충분히 길게 촬영한다. 기본 테이블 45초 퇴석 유예 때문에 수초짜리 클립은 부적절하다.
- 개인정보 동의를 받고 얼굴·음성·상호가 논문 그림에 노출되지 않게 한다. 원본 접근 권한과 비식별본을 구분한다.

## 4. 비교군

### A. 시스템 기능 평가

기본 비치물 유지/제거, 사람 이용/부재, 가림 전/후를 비교한다. 예비 단계에서는 기대 동작 표를 먼저 작성하되, 최종 수치는 GT 라벨을 기준으로 사건 단위로 산출한다.

### B. 경량화 비교

동일 영상에서 최상위 `ai_reuse=false`와 `true`를 비교한다. 두 조건의 모델, 추론 공급자, 입력 크기, 양자화, 스레드, ROI, 기준 이미지, 알림 임계값을 같게 한다. 프로세스를 새로 시작하여 캐시·누적 카운터를 초기화한다. 워밍업 구간은 동일하게 제외한다.

각 조건을 예를 들어 3회 이상 반복하고 순서를 교차한다. 실제 시간 재생에서는 처리 속도에 따라 프레임 누락이 달라질 수 있으므로, 동일 프레임을 공급하는 재생과 실시간 재생을 구분해 보고한다. 현재 on/off는 캐시뿐 아니라 안전 감사 우선권도 함께 바뀌는 정책 묶음 비교다. 캐시 단독 기여를 주장하려면 별도 절제 실험 플래그가 필요하다.

## 5. 정답 라벨과 알림 매칭 규칙

영상별로 아래 시각을 라벨링한다.

- `t_onset`: 물체가 남거나 오염 모사가 시작된 시각.
- `t_visible`: 가림이 해제되어 확인 가능해진 시각.
- `t_departure`: 사람이 실제로 떠난 시각.
- `t_eligible`: 논문에서 정한 판정 가능 시각. 테이블은 관측 가능 상태와 퇴석 유예를 고려한다.
- `t_alert`: 최초 해당 청소 알림의 내부 시각.
- `t_removed`, `t_clear`: 실제 제거 및 알림 해제 시각.

알림 허용 시간창 W와 공간 매칭 규칙은 결과를 보기 전에 정한다. 제안 예시는 같은 표면·같은 사건에 대해 t_eligible부터 confirm_seconds+여유시간 이내에 최초 알림이 있으면 TP로 매칭하는 방식이다. 여유시간은 프레임 속도·목표 서비스 지연을 근거로 정하고 문서화한다. 무한정 기다리면 발생하는 알림을 모두 TP로 세지 않는다.

지속된 알림은 한 사건으로 세고, 같은 사건에 대한 추가 알림의 중복 처리 규칙도 미리 정한다. GT 사건과 매칭되지 않은 청소 알림은 FP, 시간창 안에 알림이 없는 GT는 FN이다. 동물 알림과 청소 알림은 별도 종류로 평가한다.

가림이나 카메라 이상으로 끝까지 판정할 수 없는 구간은 별도 ‘관측 불가’로 기록한다. 어려운 사건을 임의로 제외하지 말고 수와 비율을 보고한다. 관측 가능한 시간 비율도 제공하면 ‘판정 보류가 많아서 오탐이 적어 보이는’ 문제를 드러낼 수 있다.

## 6. 필수 수치

| 수치 | 정의 |
|---|---|
| 사건 precision | TP/(TP+FP), 분모 0이면 미정의 |
| 사건 recall | TP/(TP+FN), 분모 0이면 미정의 |
| F1 | 2TP/(2TP+FP+FN), 분모 0이면 미정의 |
| 오탐/시간 | FP / 평가 영상 시간(h) |
| 판정 가능 후 지연 | t_alert − t_eligible |
| 사건 발생 후 지연 | t_alert − t_onset, 의도적 퇴석 유예 포함 |
| 가림 해제 후 지연 | t_alert − t_visible, 사건 맥락 함께 기록 |
| 요청/분 | 요청 수 / 평가 시간(min) |
| 실제 AI 실행 시간 | 실제 모델 실행 누적 시간, 요청 수와 구분 |
| 캐시 오재사용 | GT상 의미 있는 변경 후 요구된 재검사를 하지 않은 사례 |

CPU 평균/p95, RSS 최대값, 프레임 나이 p95를 추가한다. CPU는 0~100%가 전체 장치 기준인지 코어별 누적 기준인지 명시한다. 감지기만 측정했는지 대시보드·영상 디코더까지 포함했는지 프로세스 범위를 명시한다. 1초 등 동일한 샘플링 주기로 수집하며 현재 저장소에는 이 자원 계측 자동 수집기가 아직 포함되지 않았다.

대시보드 PNG는 작동 예시이지 정량 성능 근거 자체가 아니다. `frame_time`은 감지기의 시계이며 브라우저 ISO 수신 시각과 직접 빼면 안 된다. 내부 이벤트 로그·프레임 타임스탬프와 GT 시간을 같은 기준으로 정렬한다.

## 7. 기록 양식

`experiment-template.csv`는 헤더만 있는 빈 양식이다. 1행은 한 영상·한 조건·한 반복 실행이다. 사건별 상세 라벨은 별도 파일로 유지한다. 측정하지 않은 값은 빈 칸으로 두며 0을 쓰지 않는다.

필수 메타데이터: 코드 커밋, 설정 JSON, 모델 파일 해시, 런타임 버전, 장치/OS, 카메라 해상도·FPS, 스레드 수, 정상 기준 등록 방식, 영상 ID 및 split, 실험 순서, 시작/종료 시각. 원본 이벤트 로그와 상태 계측을 보관한다.

현재 제공하는 `synthetic-results.csv`는 합성 테스트 9→1회만 담는다. 실제 영상 결과와 섞어 평균 내지 않는다. 대시보드의 재사용 관측 수를 CSV의 실제 실행 감소로 대입하지 않는다.

## 8. 2페이지에 넣을 최종 결과

1. 실제 영상 장면별 사건 검출/전체, 오탐 수, 알림 지연을 표 하나로 제시한다.
2. 같은 표에 OFF/ON 요청/분 또는 실제 추론 누적 시간을 넣는다.
3. 실패 사례 하나(가림, 비슷한 색 교체 등)를 짧게 설명한다.
4. 표의 사건 수·관측 불가 비율·시간창 정의를 빠뜨리지 않는다.

모든 표를 채울 시간이 없다면 범위를 ‘구현 및 예비 실험’으로 명확히 하고 실제로 수행한 장면만 주장한다. 실험 완료 전 초안의 표는 미측정으로 유지한다.
