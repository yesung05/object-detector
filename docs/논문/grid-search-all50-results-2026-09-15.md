## 2. quality_coverage 제약 이슈

설정된 `min_quality_coverage=0.96`은 all50 전체 48/50=0.96을 기준으로 설정됐다.
그러나 primary 지표는 S33을 제외하므로 분모가 49개이고, S39·S45가 품질 무효(quality code 2)여서
**47/49 = 0.9592 < 0.96** → 모든 18개 후보가 quality 제약에 걸려 `best=null`로 기록됐다.

품질 무효는 파라미터 변경으로 개선할 수 없는 고정 조건이므로, **0.959**로 제약을 낮춰야 한다.
FP 제약(≤12)은 유지한다.
