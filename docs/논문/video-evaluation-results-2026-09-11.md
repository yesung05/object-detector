## 확인된 문제

### 1. 작은 물체·낮은 대비에서 확인 증거가 유지되지 않음

S44의 최대 누적 증거는 8.5초, S16은 3.0초, S49는 12.5초로, 테이블 확인 기준 15초에 도달하지 못했다. 후보가 생겼다는 것과 알림이 발생했다는 것은 다르다. 현재 구현은 후보 박스 IoU가 0.8보다 낮아지거나 후보가 관측에서 사라지면 증거를 초기화한다. 작은 물체의 변화 영역이 흔들릴 때 확인 시간이 반복 초기화되는 경로가 원인 후보다. 낮은 대비가 유일한 원인이라고 확정하지 않는다.

S45는 최대 증거 1.5초이며 평가 시점 자체가 가림 상태였다. 실제 가림인지 사람 검출 박스에 따른 과도한 마스킹인지는 별도 위치 검토가 필요하다.

### 2. 의자 가까운 ROI 경계의 오탐

S08의 알림 박스는 정규화 좌표 `[0.2503,0.8132,0.2842,0.8381]`, `[0.2202,0.6055,0.2503,0.6636]`이고 S12는 `[0.2090,0.6013,0.2503,0.6512]`다. 앞선 영상 검토상 정상 반출 후의 테이블 왼쪽 경계·의자 가까운 위치다. ROI에 포함된 비상판 픽셀, 의자 이동과 그림자의 영향을 먼저 확인할 필요가 있다. 이번 평가 중 ROI는 수정하지 않았다.

### 3. 이용 중 상태가 거의 잡히지 않음

21개 중 `occupied` 샘플이 나온 것은 S27(11개)과 S08(1개)뿐이다. 나머지 19개는 0개다. 많은 시나리오에 착석 동작이 계획되어 있으므로 현재 이용 구역과 사람 anchor의 대응을 검토해야 한다. 이 결과만으로 사람이 실제 앉아 있었던 총 시간을 확정하지는 않는다. 평가 어댑터에는 운영 트래커가 없으므로 운영 환경과의 차이도 함께 고려한다.

### 4. 체크포인트와 전체 영상 결과가 다를 수 있음

- S18: 약 91.5초에 한 번 알림이 발생했지만 평가 시점 약 170.5초에는 없어 FN이다. ‘한 번도 컵을 감지하지 못했다’가 아니라 알림 유지/소실 문제까지 확인해야 한다.
- S15: 평가 시점에는 TN이지만 약 243.5초에 알림이 생긴다. 종료 부근의 정상 표면과 대조할 추가 오탐 후보다.

따라서 정상 체크포인트 오탐 2건을 영상 전체 오탐의 총수로 해석하면 안 된다. 최초 알림 시각은 원본 시작 기준 출력 시각일 뿐, 실제 물체 배치부터의 지연 값이 아니다.

## 실제 모델 실행 확인

사람 모델 호출 **10,360회**, 물체 모델 호출 **1,753회**를 수행했다. 모델 호출 구간 누적 경과시간은 각각 약 207.92초, 32.78초다. 이 값은 CPU 사용률·전체 디코딩 시간·실시간 FPS·유료 API 사용량이 아니다. 실제 모델 파일 두 개의 SHA-256은 평가 전후 동일했다. AI 재사용 ON만 실행했으므로 OFF 대비 절감률은 산출하지 않았다.

표면 모듈 기존 단위 테스트는 통과했다. 하지만 단위 테스트 통과와 이번 실제 장면 성능은 별개의 결과다.

## 해석과 우선순위

현재 조건에서 잔류 양성 10개 중 5개만 평가 시점에 알림을 유지하므로, 그대로 높은 정확도나 안정성을 주장하기 어렵다. 우선 개선 방향은 다음과 같다. 이번 요청에서는 평가만 수행하고 감지 정책을 변경하지 않았다.

1. 실제 상판에 맞춘 ROI 경계와 착석 위치에 맞춘 이용 구역 검토.
2. 작은 후보의 박스 변화에 대한 증거 초기화 조건 검토.
3. 가림 중 증거 보존·가림 해제 후 재확인, 이미 발생한 알림의 유지/해제 원인 분석.
4. 개선 전 결과를 고정 보존하고 동일 영상으로 전후 비교. 이 21개는 개발용 자료로 보고, 최종 일반화 평가는 별도 자료로 수행.
