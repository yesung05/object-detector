# 별도 논문용 대시보드

## 실행

1. 기존 실행 방법으로 감지기를 켜고 표면 ROI·정상 모습을 설정한다.
2. 프로젝트 루트의 `run-research.bat`을 실행한다. `dashboard/research.html`을 직접 열어도 된다.
3. 기본 영상 포트는 8081이다. 감지기의 포트와 맞춘다.
4. 서버를 새로 빌드한 경우 `http://localhost:8080/research`에서도 같은 화면을 볼 수 있다.

별도 화면은 HTML 한 파일이며 외부 폰트·CDN·프레임워크 없이 동작한다. 파일로 열면 localhost의 감지기에 연결하므로 기존 대시보드 EXE가 실행 중이어도 새 화면을 사용할 수 있다. `/research` 주소만 새 서버 라우트 빌드가 필요하다. 이 화면 자체가 카메라나 AI를 실행하지는 않는다.

## 범위

표면 감시 모듈만 읽기 전용으로 표시한다. 쓰러짐·문 감시·체류 시간·회사명·로고·다른 관리 탭은 표시하지 않는다. ROI 수정과 기준 재등록은 기존 설정 화면에서 수행한다. 새 화면의 연결·고정·다운로드 버튼은 서버 설정을 변경하지 않는다.

사용자가 붙인 영역 ID는 화면에서 테이블/바닥/벽 및 순서 번호로 익명화한다. JSON 관측 내보내기도 원래 영역 ID나 기준 파일 경로를 담지 않는다. 번호는 이 화면의 전체 영역 순서 기준이며 설정이 바뀌면 달라질 수 있다.

## 논문 그림 만들기

- **발표 화면:** 연결·저장 도구를 숨긴다. 우측 아래 ‘일반 화면으로’로 복귀한다.
- **화면 고정:** 그 순간의 표시를 고정한다. 고정 상태와 수신 시각이 명시되며, 이후 실시간 상태로 오해하지 않도록 한다.
- **그림 PNG 저장:** 상태 카드와 실제 수치를 고해상도 이미지로 저장한다. 카메라를 표시한 경우 그 영상도 포함한다.
- **인쇄 / PDF:** 브라우저 인쇄를 이용한다. 주소가 회사명·로컬 사용자 정보를 노출하지 않도록 인쇄 설정에서 브라우저 머리글/바닥글을 끈다.
- **관측 수치 JSON:** 해당 시점의 상태·계측 카운터를 저장한다. 영상 파일이나 장시간 실험 로그의 대체물이 아니다.

논문 예시 캡션:

> 그림 2. 표면별 상태와 청소 확인 알림을 제공하는 독립 모니터링 화면. 수치는 해당 실행의 누적 검사 요청 및 재사용 관측 수이며, 카메라 영상과 상태는 비동기적으로 수신된다.

## 회사명 및 개인정보 확인

대시보드 UI·생성된 카드·제공 구조도에는 회사명이나 로고를 넣지 않았다. 다만 실제 카메라 영상의 간판, 모니터 화면, 제품 로고, 얼굴은 자동으로 제거하지 않는다. 카메라는 기본 숨김이다. 카메라 포함 캡처를 사용할 경우 촬영 단계에서 로고가 없는 배경과 동의한 참가자를 사용하거나, 공개 전 개인정보/로고를 비식별 처리해야 한다. 실제 영상은 기존 감지기의 다른 주석을 포함할 수 있다.

## 수치와 시각의 의미

- AI 검사 요청: 프로세스 내 누적 요청 수. 모델 실행 성공 횟수가 아니다.
- 결과 재사용 관측: 재사용이 가능하다고 판단한 후보·표면 관측 횟수. 절감한 호출 횟수가 아니다.
- 미지원·연결 실패 값은 ‘—’로 표시한다. 측정한 0과 미측정을 구분한다.
- 상태 갱신이 4초 넘게 멈추면 현재 상태를 모른다고 표시한다. 개별 표면 관측도 오래되면 확인 필요로 표시한다.
- 영상과 상태는 각각 별도 요청이므로 동일 프레임이 아니다. 둘의 수신 시각을 확인한다. 이 화면으로 밀리초 단위 알림 지연을 측정해서는 안 된다.
- 카메라 표시를 켜면 최대 약 2초에 한 번 스냅샷을 추가 요청한다. 성능 실험에서는 OFF/ON 양쪽의 대시보드 조건을 같게 하거나 닫아서 UI 부하를 통제한다.
- 모델/감지기가 없는 경우 가짜 시연값을 표시하지 않는다.

## 구현 검증 기록

2026-09-11: 별도 서버 빌드에서 `/research` 응답과 기존 설정 API 회귀 테스트를 통과했다. `scripts/test_research_dashboard.js`로 정상/알림/가림, 프레임 갱신 중단, 화면 고정·복귀, ID 익명화, 미지원 값, 연결 실패, 내보내기 이벤트를 검증했다. 이 자동 UI 테스트는 DOM·캔버스 대역을 사용하며 실제 PNG의 픽셀 검증은 아니다.

별도로 headless Chrome에서 파일 직접 열기 및 실제 화면 캡처를 확인했다. 카메라는 숨김 상태였으며 실제 감지기의 표면 상태가 표시되었다. 당시 감지기는 AI 스케줄러 카운터를 제공하지 않아 해당 값이 ‘—’로 표시되었다. 새 계측값을 사용하려면 새 감지기 바이너리를 적용해야 한다.
