## 2. 어떤 데이터와 방식으로 평가했나

실험 장소는 카페가 아니라 사무실이며, 사진에서 가장 크게 보이는 동일한 흰색 테이블에서 주 실험자 1명이 행동했다. 모니터·파티션 등 기존 환경과 배경 인물이 포함된다. 따라서 실제 무인 매장 전체 환경의 대표 데이터라고 주장하지 않는다.

- 원본 23개 중 S17은 잔류물 판단이 불명확하고 S38은 초기 물체 상태가 불명확하여 평가 전에 제외했다. S36·S32는 건너뛴 시나리오다.
- S06은 중간 종료 영상이지만 선택한 평가 시점이 존재하여 포함했다. 제거 완료 성능을 확인하는 자료는 아니다.
- 잔류물 있음 10개, 없음 11개다. 영상마다 관찰 후반의 육안 판정 체크포인트 하나를 사용했다.
- 원본 VP8 WebM 1280×720 영상을 2 Hz RGB 프레임으로 변환하고 실제 ONNX 사람·물체 모델과 표면 감지 모듈을 실행했다.
- 각 영상은 별도의 상태·기준 저장 공간에서 시작하고 영상 15초부터 가림 없는 5회 관측으로 기준을 구성하도록 했다. 평가는 table-1만 대상으로 한다.
- 체크포인트에 가장 가까운 2 Hz 예측(최대 0.25초 차이)에서 알림 존재 여부를 비교했다. 개별 쓰레기 종류나 박스 위치 정확도를 평가한 것은 아니다.
- 유효 품질 비율은 모든 조합에서 20/21=95.2%다. S45의 평가 시점은 품질 코드 2이며, 알림 전달 평가에서는 FN으로 포함했다. 이를 정상·깨끗함으로 해석하지 않는다.

평가기는 실제 감지 코드를 사용하지만 운영 시스템과 완전히 같지는 않다. 매 표본마다 사람 추론을 수행하고 운영 추적기를 사용하지 않으며, 카메라 정상 상태를 가정한다. 물체 AI는 동기식으로 수행하므로 운영 비동기 처리 지연을 재현하지 않는다. AI 재사용은 켠 상태만 평가했다. 자세한 설정·방법은 [평가 방법](video-evaluation-method-2026-09-11.md), 초기 오차 분석은 [초기 결과](video-evaluation-results-2026-09-11.md)를 참고한다.

**이 수치는 동일 개발 데이터의 단일 체크포인트 튜닝 점수다. 전체 영상 사건 단위 성능이나 독립 테스트 성능이 아니다.**

## 4. 탐색 공간과 선택 기준

탐색 공간: threshold ∈ {16,24,32}, min_area ∈ {0.001,0.003}, confirm_seconds ∈ {5,10,15}. ROI, 이용 구역, 모델, 증거 초기화 로직, 퇴석 유예는 고정했다. 모델 재학습은 수행하지 않았다.

선택 순서는 다음과 같다.

1. 21개 영상 모두 평가 완료.
2. FP ≤ 2 및 품질 유효 비율 ≥ 95%.
3. 통과한 조합 중 F1 최대.
4. 동점이면 FP가 적은 순, 유효 품질 비율이 높은 순, 후보 ID 순.

이 조건을 통과한 후보는 00과 17이다. F1만 최대화하면 후보 11이지만 오탐이 3건으로 증가하여 선정하지 않았다. 추천값은 **정해 둔 18개 후보 중 제약을 만족하는 최선**이지 전역 최적값이 아니다.

## 8. 논문에 지금 쓸 수 있는 내용

### 결과 문단 예시

> 사무실의 동일 테이블에서 촬영한 영상 중 초기 상태 또는 정답 판정이 불명확한 2개를 제외한 21개를 개발 평가에 사용하였다. 각 영상의 관찰 후반 체크포인트에서 잔류물 유무와 알림 유무를 비교하였다. 변화 임계값, 최소 후보 면적 비율, 확인 시간의 18개 조합을 탐색하였으며, 오탐 수 2건 이하와 품질 유효 비율 95% 이상을 제약으로 두었다. 선정된 조합은 임계값 32, 최소 면적 비율 0.003, 확인 시간 15초였고, TP 6, FP 2, TN 9, FN 4를 기록하였다. 초기 설정 대비 F1은 58.8%에서 66.7%로 증가하였으나, 동일 개발 자료에서 선택한 결과이므로 독립 테스트의 일반화 성능을 의미하지 않는다.

2페이지 논문에는 3절의 초기/추천 비교 표를 축약하여 넣고, 전체 조합 표는 부록·프로젝트 자료로 남길 수 있다. 관련 연구 인용은 [기존 관련 연구 문서](related-work.md)와 [최적화 문헌](optimization-literature.md)을 사용하되, 이 실험 결과의 근거는 외부 논문이 아니라 본 프로젝트의 실제 로그다.

현재 주장하면 안 되는 내용:

- 전체 시스템 정확도가 71.4%라거나 실제 무인 매장에서도 같은 성능이라는 주장.
- 전체 영상 사건 단위 F1, 퇴석 후 정확한 탐지 지연, 시간당 오탐 수.
- 쓰레기 종류별 분류 정확도, 박스 검출 mAP, 동물·배설물·벽·바닥 감지 성능.
- AI 재사용으로 CPU가 몇 % 줄었다거나 FPS가 몇 배 높아졌다는 주장. 이번 탐색은 ON/OFF 효율 비교가 아니다.
- 378개의 독립 영상으로 검증했다는 표현. 독립 원본은 21개다.

## 9. 다음 실험을 할 때

1. 기존 21개는 개발 세트로 유지한다. 모든 결과를 이미 보았으므로 지금 일부를 떼어 새로운 독립 테스트라고 부르지 않는다.
2. 설정·모델·코드·ROI를 먼저 고정하고 별도 날짜/세션 영상을 새로 촬영한다. 같은 영상의 프레임을 무작위로 나누는 방식은 세션 독립 검증을 대체하지 못한다.
3. 깨끗하게 떠남, 물건 만지고 가져감, 컵/쓰레기 남김, 가림 후 재노출, 의자 이동·그림자 등 양성/음성을 포함한다. 영상별 정답뿐 아니라 실제 배치·퇴석·가림·재노출·제거 시각을 라벨링한다. 녹화 안내/TTS 시각은 실제 행동 시각이 아니다.
4. 사건 매칭 허용 시간, 알림 병합 규칙, 평가 가능 구간을 결과 확인 전에 정한다. 사건 정밀도·재현율, 사용 중 오탐, 시간당 오탐, 알림 지연 중앙값/상위 분위수, 제거 후 해제 지연을 측정한다.
5. 효율 실험은 동일 영상·동일 설정·동일 하드웨어에서 재사용 OFF/ON을 비교한다. 실제 AI 호출 수, CPU, 메모리, 처리 시간과 판정 변화도 함께 기록한다. 휴식 포함 전체 탐색 시간을 효율 비교에 쓰지 않는다.

추가 촬영 수는 독립 검증 범위와 시간에 맞춰 정한다. 지금 당장 50개를 모두 채워야 이번 결과를 보존할 수 있는 것은 아니다. 다만 현재 결과만으로는 예비 실험이라는 한계를 명시해야 한다.

## 10. 파일 위치와 재현 자료

아래 경로는 프로젝트 루트 기준이다. 원본 영상과 runs 결과는 이 문서에 포함된 것이 아니므로 문서만 복사하면 재현 자료가 보존되지 않는다.

| 자료 | 경로 / 용도 |
|---|---|
| 최종 탐색 폴더 | `runs/surface-search/search-KqZcln/` |
| 완료 확인 | `completed.json` — 최종 추천과 운영 미변경 여부 |
| 탐색 정의 | `search.json` — 범위·제약·휴식·서명 |
| 전체 점수 | `leaderboard.json` |
| 추천 설정 | `best-config.json` — 평가용 table-1 설정만 포함 |
| 후보별 결과 | `candidate-XX/summary.json`, 신규 실행의 `candidate-XX/Sxx/result.json` 및 예측 로그 |
| 초기값 보존 | `runs/surface-search/baseline-EQYvBO/` — 설정·모델·평가기·소스·초기 결과·해시 |
| 초기 실제 평가 | `runs/video-evaluation-3yhvPj/` |
| 원본 영상 | `records/session-2026-09-11T07-12-10-284Z-7d0c50b3/` |
| 육안 검토 자료 | `runs/record-audit-6l5Wca/` |
| 실행 로그 | `runs/surface-search/launch-3f7bb2d1/stdout.log`, `stderr.log` |
| 탐색 프로그램 | `scripts/surface_grid_search.js` |
| 영상 평가기 | `tests/evaluate_surface_video.c` |
| 운영 설정 | `config/surfaces.json` |

초기 스냅샷은 영상을 중복 복사하지 않고 경로와 SHA-256을 기록한다. 모델·실행 파일·DLL·주요 소스는 스냅샷에 보존되어 있다. 원본 영상은 이동·편집하지 않고 함께 백업해야 한다. candidate-00은 초기 평가를 재사용했으므로 신규 357건과 구별한다.

실행 환경은 Windows CPU 평가, ONNX Runtime 1.26.0, 추론 스레드 1개, confidence=0.25, IoU=0.45다. 사람 모델은 `yolo11n-pose-416x224.onnx`, 물체 모델은 `yolo11n_tier2_fp32.onnx`다. 세부 재현 절차는 [Grid Search 실행 문서](surface-grid-search.md)에 있다.
