# Tier 2 정확도 및 오탐 점검

## 결론

모델 자체의 제한된 정밀도와 앱의 클래스 ID 불일치가 동시에 확인됐다. 이번 작업은 진단만 수행했으며 배포 모델, 앱 코드, 임계값을 변경하지 않았다.

## 1. 우선 해결할 앱 불일치

실제 배포 ONNX 두 파일의 metadata 및 출력 shape는 7클래스 모델이다: `[1,11,2100]`, 입력 `[1,3,320,320]`.

| ID | 모델 의미 | 현재 앱 처리 |
|---|---|---|
| 0 / 1 | cat / dog | 동물 — 일치 |
| 2 / 3 | bottle / cup | 음료 / 컵 — 일치 |
| 4 | food | 음식 — 일치 |
| 5 | chair | 음식 — 불일치 |
| 6 | dining table | 음식 — 불일치 |

`include/rules.h`는 FOOD=4..13, CHAIR=14, DININGTABLE=15로 정의한다. `src/postprocess.c`는 출력 클래스 인덱스를 그대로 전달하며, `src/draw.c`와 `src/rules.c`는 해당 상수를 사용한다. 따라서 현재 소스에서는 의자·테이블이 FOOD로 표시되고 가구 기반 규칙에서도 누락된다. 실행 중인 바이너리의 동일성이나 사용자가 본 특정 프레임까지 검증한 것은 아니다.

## 2. 배포 ONNX 재평가

- 데이터: `datasets/tier2_v3/tier2_v2.yaml`의 val 전체 3,315장. 배경 전용 이미지 0장.
- ONNX Runtime CPU, 320×320 letterbox, batch=1, conf=0.001, NMS IoU=0.45.
- Ultralytics 표준 검증 사용. 앱의 argmax 및 클래스 비구분 NMS와 완전히 같은 경로는 아니므로 실시간 앱 오탐률로 해석하지 않는다.
- val은 학습 중 모델 선택에 사용된 데이터이며 독립 현장 평가가 아니다. mAP는 단순한 정답 비율이 아니다.

| 모델 | mAP50 | mAP50–95 |
|---|---:|---:|
| FP32 | 0.5081 | 0.3434 |
| INT8 | 0.4800 | 0.3129 |

INT8는 FP32보다 각각 2.81%p / 3.05%p 낮다. `run.bat`과 `run-all.ps1`은 INT8를 우선 선택하며 confidence=0.20을 전달한다. `src/main.c`의 Tier 2 옵션은 Pose 옵션을 복사하므로 이 임계값을 공유한다. 실제 실행 옵션이 다르면 적용값도 다르다.

## 3. 클래스별 정확도와 낮은 confidence 영향

Precision/Recall은 IoU=0.5 기준 검증 confidence 곡선에서 해당 임계값에 가장 가까운 지점을 사용한 근사치다. 클래스 ID 해석 오류를 적용하지 않은 모델 자체 평가다.

| 클래스 | FP32 AP50 | INT8 AP50 | INT8 정밀도 @0.20 | INT8 재현율 @0.20 | INT8 정밀도 @0.35 | INT8 재현율 @0.35 |
|---|---:|---:|---:|---:|---:|---:|
| 고양이 | .8086 | .7736 | .7435 | .7600 | .8035 | .6971 |
| 개 | .7012 | .6549 | .6835 | .6234 | .7535 | .5810 |
| 병 | .3290 | .3114 | .5113 | .2995 | .6818 | .2230 |
| 컵 | .3968 | .3629 | .5618 | .3332 | .6927 | .2779 |
| 음식 | .4548 | .4394 | .5701 | .4195 | .6698 | .3497 |
| 의자 | .3358 | .3160 | .4959 | .3163 | .6489 | .2399 |
| 식탁 | .5307 | .5020 | .6747 | .4925 | .7575 | .4082 |

병·컵·음식·의자는 0.20에서 정밀도가 약 50~57% 수준이다. 이는 이 검증 조건에서 해당 클래스 예측 중 약 43~50%가 정답 매칭되지 않는다는 뜻이며, 모든 영상 프레임의 오탐 확률이나 배경 false-positive rate는 아니다. confidence를 올리면 오탐이 줄지만 이미 낮은 재현율도 더 떨어진다.

## 4. 권장 순서 (미적용)

1. 7/16클래스 모델을 구분해 ID 매핑을 수정하고 의자·테이블 표시 및 룰 테스트를 추가한다.
2. Pose와 독립적인 Tier 2 confidence를 마련한 뒤 0.20/0.35/0.50을 현장 데이터로 비교한다. 전역 confidence를 무작정 올리면 Pose에도 영향을 준다.
3. 동일한 현장 영상에서 FP32/INT8를 비교해 정확도와 속도 절충을 결정한다.
4. 실제 오탐 프레임, 빈 매장, 반사·그림자·포스터 등 배경 예시를 수집하고 라벨 검수 후 추가 학습한다. 별도의 현장 평가 세트를 유지한다.
