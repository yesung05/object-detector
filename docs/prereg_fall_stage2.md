# 쓰러짐 2차 AI — 사전 등록 (학습·평가 결과를 보기 전에 고정, 2026-11-07)

> **데이터 출처**: AI-Hub 「실내(편의점, 매장) 사람 이상행동 데이터」(과학기술정보통신부·한국지능정보사회진흥원 「지능정보산업 인프라 조성」 사업의 결과물). 이 문서와 이후 결과 문서는 그 2차적 저작물이다. 프레임(가공본 포함)은 AI 도구로 열지 않는다 — 수치와 텍스트 출력만 본다. 상업 탑재 근거인 AI-Hub 회신 원문은 아직 저장소에 없다(README) — 배포 전 보관 필요.

앞 단계: 쓰러짐 룰은 현장 설정 pool 21%, 보강 프로파일 P3 44%(오탐 0)이며 기본 꺼짐이다([개선 결과](anomaly-dataset-improvements-2026-11-05.md)).
병목은 포즈 모델이 누운 사람에서 무너지는 것([진단](pose-aihub-gt-diagnosis-2026-11-07.md)). 폭행처럼 **느슨한 1차 게이트 + 작은 시계열 분류기(2차)** 로
관절 하나하나의 판정 대신 "몇 초 동안의 몸 모양 변화"를 보게 한다. 구조·후보·하이퍼파라미터는 [폭행 2차](prereg_fight_stage2.md)와 같게 둔다.

## 고정 사항
**입력** (`scripts/fall2_extract.py`): 배포 포즈 모델 `yolo11n-pose-416x224` FP32 가 낸 검출·관절 CSV(정답 관절 아님).
포즈 파인튜닝 3차가 Go 여도 **이 실험은 원본 모델 특징으로 한다**(파인튜닝 모델은 pool 프레임을 봐서 교차검증이 낙관적이 된다).
- 창: 9프레임(3fps 에서 3초), 이동 3.
- 프레임마다 "가장 가로로 누운 사람"(박스 가로/세로 최대) 한 명: 박스 기준 정규화 17관절×(x, y, 점수) 51 + log(가로/세로) + 창 안 최대 키 대비 키 + 박스 중심 y/화면 높이 + 사람 수/4 + 유효 → 56차원.
- **게이트(1차, 호출 조건)**: 창 9프레임 중 5프레임 이상 사람이 있고, (가로/세로 ≥ 1.0 인 프레임이 3개 이상) 또는 (창 안 최소 키 ≤ 최대 키의 0.6).
  이 게이트를 통과한 창만 학습·평가·추론에 쓴다.

**라벨**: 양성 = 전도(07) 클립에서 창의 50% 이상이 정답 구간 안. 음성 = 다른 모든 클래스(08~14, 휠체어·목발 14 포함)의 게이트 통과 창 + 전도 클립의 정답 앞뒤 2초 밖. 그 사이는 제외.
클립: 전도 dev+pool 전부, 음성 클래스는 클래스당 장면 80개(시드 0, 장면당 1클립).

**분할**: dev+pool 합본의 **매장 단위 leave-one-store-out 교차검증(7개)**. **전도 test 는 이미 룰 평가에 소진**되어 이 실험에 깨끗한 최종 확인 세트가 없다 — 교차검증 수치가 최종이며, 매장 그림자 운영이 유일한 다음 확인이다.

**모델·학습**: 후보 3개(1D-CNN / GRU / MLP 풀링), 고정 하이퍼파라미터(AdamW 1e-3, 40에폭, 배치 256, 가중 BCE, 시드 0), 선택 = 7폴드 합산 PR-AUC 최고. `scripts/fight2_train.py` 를 `--positive-class 07` 로 그대로 쓴다.

**결정 규칙(클립)**: 연속 4개 창 안에 임계값 이상 창 2개 이상 → `person_fallen` 후보. 정답 구간 앞 1초~뒤 3초 안이면 검출, 그 밖은 오탐.
임계값 = 교차검증 예측에서 **음성 시간당 오탐 ≤ 0.5** 를 만족하는 가장 낮은 값(폭행 2.0 보다 엄격 — 쓰러짐 룰 P3 의 오탐이 0 이었다).

## Go / No-Go
| 기준 | 값 |
|---|---|
| 교차검증 합산 클립 재현율 | **≥ 0.55** (룰 P3 pool 44% 대비) |
| 같은 임계값에서 오탐 | **≤ 0.5 건/시간** |
| 매장별 최저 재현율 | **≥ 0.35** |
| 휠체어·목발(14) 클립 오탐 | **0 건** |
| 모델 크기·지연 | < 100KB, < 2 ms/창 |
하나라도 못 넘으면 No-Go 로 기록하고 C 런타임에는 넣지 않는다. Go 여도 기본 꺼짐(그림자 가능), 출시 프로파일에 넣지 않는다.

## 미리 적는 한계
- 연출 3fps, 매장 7곳, 앉아 있는 손님이 거의 없다 — **카페 오탐(의자에서 몸을 숙이기, 바닥에 앉은 아이)은 미측정**.
- 전도 test 소진으로 교차검증 외 확인 세트가 없다. 7개 매장 점수는 서로 독립이 아니다.
- 게이트는 원본 포즈 모델 기준이다. 포즈 모델을 바꾸면 다시 학습·평가해야 한다.
