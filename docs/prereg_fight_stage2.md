# 폭행 2차 AI — 사전 등록 (학습·평가 결과를 보기 전에 고정, 2026-11-06)

> **데이터 출처**: AI-Hub 「실내(편의점, 매장) 사람 이상행동 데이터」(과학기술정보통신부·한국지능정보사회진흥원 「지능정보산업 인프라 조성」 사업의 결과물). 이 문서와 이후 결과 문서는 그 2차적 저작물이다. 이용 범위(평가·진단, 규칙 파라미터 배포, 학습 모델의 상업 탑재)는 AI-Hub 회신으로 확인했다([README](../README.md#평가-데이터-출처-ai-hub)). 이 데이터의 프레임(가공본 포함)은 AI 도구로 열지 않는다 — 수치와 텍스트 출력만 본다.

앞 단계 결과([1단계 측정](anomaly-multiclass-stage1-dev-2026-11-06.md)): 폭행(13)은 1차 특징 `fight_score`가 엄격 TPR 0.844(Go 0.90 미달)였고 AUC 0.96/0.835로 신호는 있었다. 그래서 **의심 구간에만 호출하는 소형 분류기(2차 AI)**를 만든다. 브랜치: `feat/fight-stage2`.

## 고정 사항

**입력(추론 캐시/검출 CSV에서 얻은 실제 검출 키포인트)**
- 정답 관절로 학습하지 않는다(배포 분포와 달라지는 문제: 쓰러짐 점수 붕괴 사례). 모델은 `yolo11n-pose-416x224` FP32가 낸 검출·관절 CSV만 쓴다.
- 창(window): 9프레임(3fps에서 3초), 이동 3프레임. 프레임마다 가장 가까운 두 사람(중심 거리)을 고르고, 두 사람을 중심 x 좌표 순으로 정렬한다.
- 프레임 특징: 쌍 외접 박스 기준 정규화 좌표의 17관절×(x, y, 점수)를 두 사람 분 + 쌍 기하(중심거리/평균 키, IoU, 키 비율) + 사람 수 → 약 106차원. 이전 프레임 대비 변위는 모델이 시계열에서 배운다.
- **게이트(1차 필터, 호출 조건)**: 창 안 9프레임 중 5프레임 이상에서 사람이 2명 이상이고, 그중 3프레임 이상에서 `pair_close ≥ 0.2`(=두 사람 중심거리가 평균 키×1.2 이내). 이 게이트를 통과한 창만 학습·평가·추론에 쓴다(평소 CPU 비용 0).

**라벨**
- 양성: 폭행(13) 클립에서 창의 50% 이상이 정답 구간 `[start,end]` 안에 있는 창.
- 음성: (a) 폭행이 아닌 모든 클래스(07,08,09,10,11,12,14)의 클립의 모든 게이트 통과 창, (b) 폭행 클립에서 정답 구간 앞뒤 2초 밖의 창. 정답 구간에 걸치지만 50% 미만인 창은 학습·평가에서 제외한다(경계 모호).
- 클립 수: 폭행 dev+pool 638개 전부, 음성 클래스 클립은 클래스당 80개를 장면 키 단위로 무작위(시드 0) 추출.

**분할(누수 방지)**
- 학습·검증은 **dev+pool 합본에서 매장 단위 leave-one-store-out 교차검증(7개 매장)**. 한 사건을 카메라 6대가 찍으므로 장면 키 단위로 같은 폴드에 둔다(매장 단위 분할이 이를 포함한다). 새 매장 일반화 지표가 된다.
- **test(80클립)**는 최종 모델 1개와 임계값 1개를 고정한 뒤 **한 번만** 쓴다. 보고 후 재튜닝 금지.

**모델·학습**
- 후보 3개만: ① 1D-CNN(시간축 합성곱 2층), ② GRU(은닉 48), ③ 작은 MLP(평균+표준편차 풀링). 하이퍼파라미터 탐색 없음(고정: AdamW lr 1e-3, 에폭 40, 배치 256, 가중 BCE, 시드 0). 선택 규칙: 7개 폴드 합산 PR-AUC 최고.
- 크기 < 100KB(ONNX), CPU FP32 지연 < 2 ms/창(개발 PC 기준, i5-4200U 미측정).

**결정 규칙(클립 단위)**
- 클립에서 **연속한 4개 창 안에 임계값 이상 창이 2개 이상**이면 `person_fight` 발화. 발화가 폭행 정답 구간 앞 1초~뒤 3초 안이면 검출, 그 밖의 모든 발화(폭행이 아닌 클립 포함)는 오탐.
- 임계값은 교차검증 예측(7폴드 합산)에서 **음성 시간당 오탐 ≤ 2.0 건**을 만족하는 가장 낮은 값으로 정한다(음성 시간은 클립 수×60초).

**Go / No-Go (사전 고정)**
| 기준 | 값 |
|---|---|
| 교차검증 합산 클립 재현율 | **≥ 0.75** |
| 같은 임계값에서 오탐 | **≤ 2.0 건/시간** |
| 매장별 최저 재현율(가장 나쁜 폴드) | **≥ 0.50** |
| 1차 필터만(`fight_score`) 대비 | 같은 재현율에서 오탐이 **더 적을 것** |
| 모델 크기·지연 | < 100KB, < 2 ms/창 |
하나라도 못 넘으면 **No-Go**로 기록하고 C 런타임에는 넣지 않는다. Go여도 `person_fight`는 기본 꺼짐(그림자 가능)이며 출시 프로파일에 넣지 않는다.

## 보고에 반드시 적을 한계(미리 적음)
- 연출 3fps, 배우 1~2명, 매장 7곳. 평상시 대화·악수·포옹·아이 놀이 같은 일반 음성은 이 데이터에 거의 없어 **카페 오탐률은 미측정**이다. 오탐 상한 주장에 필요한 음성 시간(rule of three, 약 72카메라시간)이 부족하면 "데이터셋 기준 값"으로만 쓴다.
- 쓰러짐·파손 등 다른 행동과의 혼동은 음성에 포함되어 평가되지만, 현장의 다른 격한 동작(춤, 운동)은 없다.
- i5-4200U 지연·CPU는 미측정.
- 매장 단위 CV라 7개 점수가 서로 독립은 아니다(같은 배우·시나리오).
