# 기능별 구현 방식 및 데이터셋 분석

> 각 기능을 어떤 방식으로 구현할지, AI 추론이 필요하다면 어떤 데이터가 필요한지 정리.
> i5-4200U (2코어 4스레드) 하드웨어 기준.

---

## 분류 기준

| 구분 | 설명 |
|---|---|
| **룰** | 조건문·타이머만으로 구현 가능, AI 불필요 |
| **경량 CV** | 픽셀 통계·배경 차분 등 고전 영상처리, AI 불필요 |
| **AI — 공개 데이터셋** | 추가 모델 필요, 공개 학습 데이터 존재 |
| **AI — 수집 필요** | 추가 모델 필요, 국내 무인카페 특화 데이터를 직접 수집해야 함 |

## 안정성·보안

### 경로 검증 (입출력 URL 차단)
- **방식**: 룰
- `://` 포함 여부 확인 또는 경로가 `/`, `C:\` 등 파일시스템 루트로 시작하는지 검사
- AI 불필요, 데이터셋 불필요

### 카메라 장애 감지
- **방식**: 경량 CV
- **백화 감지**: 프레임 전체 픽셀의 표준편차가 임계값 이하이면 단색(백화) 상태로 판단
- **프레임 타임아웃**: 마지막 프레임 수신 후 N초 이내 신규 프레임 없으면 장애 이벤트
- **암흑 감지**: 평균 밝기가 임계값 이하 (카메라 가려짐)
- AI 불필요, 데이터셋 불필요

### 통합 로깅
- **방식**: 룰
- 타임스탬프·심각도(INFO/WARN/ERROR) 포함, 파이프라인 단계별 상태 기록
- AI 불필요

## 룰 기반 감지

### 동일인 장기 추적 (Re-ID)
- **방식**: 경량 CV — **IoU + 위치 예측 기반 매칭**
- 프레임 간 박스 중심점 거리 + IoU로 동일인 판단. 무인 카페는 공간이 좁고(10m 이내) 동선이 단순해 딥러닝 Re-ID 불필요
- Kalman 필터로 이동 방향 예측 → 가려짐(occlusion) 짧게 버텨줌
- ID 소멸 조건: N프레임 연속 미감지
- **데이터셋 불필요**
- > 이후 체류 시간·미주문·인원 카운트 모두 이 기반 위에 올라감

### 체류 시간 측정
- **방식**: 룰
- Re-ID가 부여한 ID별로 입장 타임스탬프 기록, 현재 시각과 차이를 주기적으로 확인
- 임계값(예: 120분)은 매장 설정 파일에서 주입

### 미주문 착석 / 초과 장기 체류
- **방식**: 룰
- 착석 감지: 사람이 일정 구역(테이블 ROI) 안에서 N초 이상 정지
- 결제 이벤트가 없는 상태로 착석 시간 초과 → 이벤트
- 구역(ROI)은 매장 설치 시 한 번 설정

### 출입문 개방 감지
- **방식**: 경량 CV — **배경 차분(Background Subtraction)**
- 문 영역 ROI를 고정 지정 → 해당 구역의 픽셀 변화량이 임계값 이상이면 문 열림 판단
- GMM(Gaussian Mixture Model) 또는 단순 이동 평균 배경 모델로 충분
- **데이터셋 불필요**

### 인원 초과
- **방식**: 룰
- 현재 감지된 person 박스 수가 매장 설정 수용 인원 초과 시 이벤트

### 1인 1메뉴 미구입
- **방식**: 룰 (결제 DB 연동 전제)
- 감지 인원 수와 POS 주문 건수 비교, 불일치 시 이벤트

### 매장 크기별 설정
- **방식**: 룰 — JSON/INI 설정 파일
- 임계값(체류 시간, 신뢰도, 인원 한도 등)을 외부 파일로 분리, 하드코딩 금지

## AI 추론 — 공개 데이터셋으로 해결 가능

### 반려동물 의자 착석
- **방식**: AI — COCO 클래스 확장
- 현재 YOLO11n은 COCO 80클래스 전체로 학습됐으나 person(0)만 필터링 중
- **추가 작업 없음**: dog(16), cat(15), chair(56) 클래스를 함께 출력하도록 필터 해제
- 공간 관계 판단: dog/cat 박스 중심이 chair 박스 내부에 있으면 "의자 착석"으로 판단
- **별도 학습 불필요, 데이터 수집 불필요**

### 응급상황 (쓰러짐·실신)
- **방식**: 두 단계로 접근

  **1단계 — 바운딩 박스 종횡비 (즉시 적용 가능)**
  - 서 있는 사람: 박스 높이 > 너비 (세로 비율)
  - 쓰러진 사람: 박스 너비 > 높이 (가로 비율) + 박스가 화면 하단에 위치
  - 추가 조건: 해당 ID가 N초 이상 가로 비율 유지 → 방치 판단
  - **데이터셋 불필요**

  **2단계 — 포즈 추정 (정확도 향상 시)**
  - 모델: **MoveNet Lightning** (Google, 경량, i5-4200U에서 동작 확인됨)
  - 키포인트로 "눕기" 자세 판별
  - 공개 데이터셋: **UR Fall Detection Dataset**, **OCFALL**, **Le2i Fall Detection**
  - 추가 수집 필요 없음 (공개 데이터셋으로 충분)

### 노키즈존 — 어린이 감지
- **방식**: AI — 얼굴 기반 나이 추정
- 파이프라인: person 박스 → 얼굴 검출 → 나이 추정 → 18세 미만 시 이벤트
- 모델 후보:
  - **InsightFace (buffalo_sc)**: 경량, ONNX 지원, C API 호출 가능
  - **MobileNet 기반 나이 분류기**: 어린이/성인 이진 분류로 단순화 시 더 빠름
- 공개 데이터셋: **UTKFace** (23k장, 0~116세 라벨), **APPA-REAL**, **IMDB-WIKI**
- **별도 수집 불필요** — 단, 한국인 얼굴 비율이 낮아 정확도 저하 가능. 보완 필요 시 AIHub 얼굴 데이터셋 활용

## AI 추론 — 국내 무인카페 특화 데이터 수집 필요

### 외부 음식 반입·취식
- **방식**: AI — 객체 감지 (음식·용기 분류)
- COCO에 cup(41), bottle(39), bowl(45)은 있으나 "매장 음료"와 "외부 음식"을 구분하는 라벨이 없음
- **수집 방법**:
  - 파일럿 매장(노량진 등)에서 매장 음료 vs 외부 음식 구분 영상 촬영
  - 외부 음식: 편의점 도시락, 배달 음식 봉투, 포장 음식 등
  - 최소 클래스: `store_drink` / `external_food` / `none`
- 기존 Food-101, UEC Food 256은 음식 종류 분류용이라 이 목적에 직접 사용 불가
- **수집 필요**: 매장당 200~500장 이상 권장

### 시럽 과다 복용
- **방식**: 경량 CV + 룰 (AI 없이도 1차 구현 가능)
- 1차: 시럽 스테이션 구역 ROI 안에서 특정 동작(팔 올렸다 내림)이 N회 이상 반복되면 이벤트
- 배경 차분으로 해당 구역 움직임 횟수 카운트
- 정밀도 향상 시: 손·팔 동작 인식 모델 필요
- **수집 필요** (정밀 버전): 시럽 펌핑 동작 영상. 매장 촬영으로 수집 가능

### 쓰레기 투기
- **방식**: AI + 룰 조합
- 1차 (룰): 사람이 테이블/바닥에 물건을 놓고 퇴장 후 해당 위치에 객체가 남아 있으면 이벤트
- 2차 (AI): 쓰레기 객체 자체 감지
- 공개 데이터셋: **TACO** (Trash Annotations in Context, 1.5k장) — 야외 환경이라 실내 카페와 차이 있음
- **수집 필요**: 카페 내 쓰레기 방치 상황 촬영 (컵, 포장지, 영수증 등)

### 구토
- **방식**: AI — 이상 행동 감지 (anomaly detection)
- 명시적인 "구토 동작" 분류기는 학습 데이터 확보가 현실적으로 불가능
- 현실적 접근:
  - 사람이 갑자기 몸을 앞으로 숙이는 포즈 변화 감지 (포즈 추정)
  - 해당 구역 바닥에 이전에 없던 흔적 출현 (배경 차분)
  - 두 조건이 짧은 시간 내 동시 발생 시 이벤트
- **수집 현실적으로 어려움** — 포즈 이상 감지로 우회하는 것이 현실적

### 기물 파손
- **방식**: 경량 CV + 룰
- 갑작스러운 큰 움직임(optical flow 급증) + 직후 장면 구조 변화(배경 모델 대비 차이 유지)
- 파손음 감지(오디오)와 병행하면 정확도 향상 — 현재 파이프라인은 오디오 미지원
- **수집 불필요** (이상 탐지 방식이므로)

## 데이터 수집 우선순위

수집이 필요한 경우, 파일럿 매장(노량진 7평)에서 진행.

| 우선순위 | 항목 | 수집 방법 | 예상 분량 |
|---|---|---|---|
| 1 | 외부 음식 반입 | 연출 촬영 (편의점 음식, 배달 봉투 등) | 매장당 300~500장 |
| 2 | 쓰레기 방치 | 컵·포장지 바닥·테이블 위 연출 | 200~300장 |
| 3 | 시럽 남용 동작 | 시럽 펌핑 반복 동작 영상 | 10~20개 클립 |

구토는 데이터 수집보다 포즈 이상 우회 감지로 처리하는 것을 권장.
