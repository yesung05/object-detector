# Alpha 3 로그 보관 정책 — 2026-09-27

- 설정 → 자동 관리 → 현장 시험 기록에서 로그 총 용량을 MiB 단위로 지정합니다.
- 기본 상한은 10,240MiB(10GiB), 0은 용량 제한 없음입니다. 허용 범위는 0~1,048,576MiB 정수입니다.
- 보관 기간은 30일 고정입니다. 이벤트 DB·성능 DB·WAL·SHM을 한 묶음으로 취급하고, 마지막 수정 후 30일이 지난 완료 묶음을 삭제합니다.
- 용량 초과 시 30일 이내 기록도 오래된 묶음부터 삭제합니다.
- 시작 후 첫 카메라 프레임과 이후 60초마다 검사합니다. 설정 변경은 재시작 없이 반영됩니다.
- 현재 기록 중인 DB는 보호합니다. 삭제할 묶음의 모든 파일에 독점 접근이 가능해야 정리하므로 다른 프로세스가 사용하는 파일도 건너뜁니다.
- 보호된 파일만으로 상한을 넘으면 일시적으로 초과 상태를 유지합니다. 초과 및 삭제 실패는 이벤트 로그에 남깁니다.
- 대상은 로그 폴더 바로 아래의 프로그램 생성 날짜 형식 DB, 연결된 성능/보조 파일, 실행기 로그와 restarts.log입니다. 별도 이미지·영상 폴더, 사용자 파일명 DB, 하위 폴더는 포함하지 않습니다.
- 앱이 종료되어 있거나 카메라 프레임이 들어오지 않으면 정리도 진행되지 않습니다.

## 검증

CTest 8개 통과. 30일 만료, 용량 초과 시 오래된 순서, 현재 DB 보호, 파일 사용 중 묶음 보호, 무관한 파일 보존을 검사했습니다. 숨김 브라우저에서 기본값 10GiB, 설정 저장·재조회, 음수 거부, 0으로 용량 제한 해제도 확인했습니다.

## 적용

`dist/unmanned_detector-Setup-0.1.0-alpha.3-x64.exe`로 업데이트 후 다시 실행하세요. 현재 실행 중인 기존 앱은 교체하지 않았습니다. Alpha 2 설치 파일에는 이 보관 정책이 없습니다.
