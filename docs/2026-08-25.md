## 변경 사항

### 1. 카메라 자동 감지 (`media_first_video_device`)

**파일:** `include/media.h`, `src/media_ffmpeg.c`

`--camera` 실행 시 `--camera-device`를 지정하지 않아도 첫 번째 비디오 장치를 자동으로 찾는 함수를 추가했다.

```
int media_first_video_device(const char *format, char *buf, size_t bufsize);
```

FFmpeg의 `avdevice_list_input_sources()`를 사용해 dshow/v4l2/avfoundation 장치를 열거한다. Windows dshow에서는 `device_name`이 `@device_pnp_...` 형식의 하드웨어 경로이고, 친숙한 이름은 `device_description`에 있다. 따라서 `device_description`을 우선 사용해 `video=<이름>` 형식으로 반환한다.

**장치 선택 우선순위:**
1. `device_description`이 있는 비디오 장치 (친숙한 이름, 예: `e2eSoft iVCam`)
2. fallback: `device_name` 기반 (하드웨어 경로)

### 2. `main.c` — `default_camera_device()` 개선

**파일:** `src/main.c`

Windows에서 `"video=Integrated Camera"` 하드코딩을 제거하고 `media_first_video_device("dshow", ...)` 호출로 교체했다. 자동 감지 성공 시 `camera: auto-detected video=<이름>` 로그를 출력한다.

**이전:**
```c
return "video=Integrated Camera"; // 장치 이름이 기기마다 달라 오작동
```

**이후:**
```c
static char buf[256];
if (media_first_video_device("dshow", buf, sizeof(buf)) == 0)
    return buf;
return NULL;
```

### 3. `video_size`/`framerate` 기본값 제거

**파일:** `src/main.c`

`640x480`/`30fps` 기본값이 항상 dshow에 전달되어 가상 카메라(iVCam 등)가 "Could not set video options"로 열리지 않는 문제가 있었다. 기본값을 제거해 장치가 직접 포맷을 협상하게 했다. 해상도가 필요하면 `--camera-size`/`--camera-fps`로 명시한다.

### 4. dshow `rtbufsize` 증가

**파일:** `src/media_ffmpeg.c`

dshow 기본 버퍼(3MB)는 고해상도 카메라(1280x720 이상)에서 쉽게 넘쳐 "frame dropped" 경고가 발생한다. dshow 입력일 때 30MB로 늘렸다.
