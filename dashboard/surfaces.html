초록색: 감시할 표면 · 노란색: 사람이 앉는 곳. 테이블은 상판을 그린 뒤 좌석 영역도 그려주세요. 사람의 몸이 있는 곳을 포함해야 합니다.

고급 그리기 · 비치물 이동 허용 / 제외 영역

고정된 비치물은 따로 그릴 필요가 없습니다. 정상 모습에 함께 등록됩니다. 이동을 허용할 물건만 ‘비치물 추가’로 지정한 뒤 ‘마지막 비치물 이동 허용 구역’을 그리세요.

실시간 감시 상태

위생 위험 세부 분류: 미지원. 일반 변화·잔류물 감시는 동작하지만 배설물/토사물을 확정하지 않습니다.

감시 프로그램 연결 대기

설정 순서

1. 테이블·바닥·벽 버튼을 누르고 영상에 점을 3개 이상 찍은 뒤 ‘영역 확정’을 누르세요.

2. 테이블은 ‘사람이 앉는 곳 추가’로 좌석 영역도 지정하세요.

3. 설정을 저장하고 평소 비치물을 그대로 둔 채 ‘정상 모습 등록’을 누르세요. 물건별 이름이나 테두리는 필요 없습니다.

고급 설정 · 이름 / 감도 / 비치물

비치물 아래는 빈 표면 기준이 없으면 판단을 유보합니다.

2. 설정 적용

활성화하면 기존 residue/slot 청소 경로를 대신합니다. 기존 문·카메라 감시는 유지됩니다.

3. 기본 비치물 한 번에 등록

컵·휴지통 등 원래 있는 물건은 평소 자리에 두세요. 쓰레기와 오염만 치우고, 사람이 영역을 가리지 않을 때 등록하세요.

위에서 등록할 영역을 선택하세요.

물건을 하나씩 그리거나 종류를 고를 필요가 없습니다. 현재 배치 전체를 기준으로 저장합니다. 가림 없는 5회 관측 후 등록되며, 완료 여부는 실시간 감시 상태에서 확인하세요.

물건 자체를 알아보는 기능은 아닙니다. 나중에 컵이나 휴지통의 위치·모양이 달라지면 변화로 감지될 수 있습니다. 정상 배치를 바꿨다면 깨끗한지 확인하고 다시 등록하세요.

선택 사항 · 물건이 이동할 때

고급 그리기에서 이동할 비치물과 허용 구역을 지정할 수 있습니다. 제한적인 위치 이동만 비교하며 회전·모양 변화까지 보장하지 않습니다.

비치물 아래까지 비교해야 할 때만 사용하세요. 물건을 잠시 치우고 빈 표면을 등록한 뒤, 원래 배치로 되돌려 놓으세요. 기본 비치물 등록에는 필요하지 않습니다.

설정 초안 JSON · 가져오기/세부 수정

자동 설정도 같은 형식을 사용합니다. 수정 후 ‘초안 읽기’와 ‘검증하고 저장’을 순서대로 누르세요. 잠금은 자동 제안으로부터 표면 전체를 보호합니다.
