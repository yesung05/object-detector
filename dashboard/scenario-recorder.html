시험 위치: 화면 앞쪽의 가장 큰 흰색 테이블

모니터·칸막이·키보드·배선은 원래 비치물로 유지하세요. 물건은 카메라에 보이는 빈 상판에 놓고, 다른 책상과 뒤쪽 사람은 시험 대상에서 제외합니다. 이 안내는 ROI를 자동 설정하지 않습니다. 빈 컵·마른 종이로 시험하세요.

처음 한 번: 카메라와 저장 폴더를 허용해 주세요.

Chrome 또는 Edge에서 사용하세요. 감지기가 같은 카메라를 사용 중이면 충돌할 수 있습니다. 필요한 경우 사용자가 감지기를 중지한 뒤 촬영하세요. 이 도구가 감지기를 중지하거나 설정을 변경하지는 않습니다. 마이크·음성은 녹음하지 않으며 영상은 서버로 업로드하지 않습니다.

연결 전

필요한 것만 다시 촬영

프로젝트 records의 저장 상태와 기존 육안 검토를 확인합니다. 감지 오탐·미검출은 데이터 오류가 아니므로 자동 제외하지 않습니다.

기록 확인 중

완료는 파일 저장 상태이며 행동 정확성은 직접 확인해야 합니다. 다른 폴더의 영상은 집계하지 않습니다. 새 영상은 새 세션에 저장합니다.

촬영할 시나리오 선택 (기본 50개 모두)

브라우저 한국어 음성을 확인 중입니다.

설명을 다 읽은 뒤 해당 단계의 카운트다운을 시작합니다. 영상 길이에는 녹화 중 안내 시간도 추가됩니다. S33은 사전 배치와 관찰 단계를 추가합니다. 실제 행동 완료나 청결을 자동 판정하지 않습니다.

음성만 생략합니다. 준비·행동·관찰 시간은 유지합니다. 실제 녹화 시작 시 삐 소리가 납니다 (행동 시작 신호 아님).
시나리오 목록을 불러오는 중입니다.

카메라 원본만 저장합니다. 이 안내와 탐지 박스는 영상에 합성하지 않습니다.

촬영 기록

아직 저장한 영상이 없습니다.

촬영 중 탭을 숨기거나 카메라가 끊기면 부분 저장 후 멈춥니다. 절전·화면 잠금·페이지 닫기를 피하세요. 갑작스러운 종료나 저장 장치 오류 시 현재 파일 복구는 보장하지 않습니다. 저장 성공은 행동 수행 성공·정확도 평가를 의미하지 않습니다.
